- **命名约定**: 前端展示组件继续使用 `Factory*` 命名
- **文件组织**: 本轮以 `apps/web/app/strategy-market/page.tsx` 为主，不扩散到新页面
- **代码风格**: 小步补丁，优先加一个可滚动对比表，不引入外部图表库

### 3. 可复用组件清单
- `factoryRunsQ`：最近运行历史数据源
- `FactoryMetric`：卡片指标样式
- `SectionCard`：承载对比区块
- 现有 `FactoryRunDetailPanel`：保持运行历史详情能力并存

### 4. 测试策略
- **验证方式**: `diagnostics` + `git diff --check`
- **补充说明**: 当前 Node 环境缺少 `next`，不重复触发已知阻塞 build
- **关注点**:
  - 类型是否正确
  - 条件渲染是否安全
  - 视图是否只依赖现有字段

### 5. 依赖和集成点
- **数据来源**: `/strategy-market/factory/runs?limit=5`
- **页面位置**: 策略超市页现有工厂运行态卡片内部
- **后端依赖**: 无新增

### 6. 技术选型理由
- 直接做表格型对比，避免引入图表库与额外依赖
- 直接使用最近 5 次历史记录，保证信息密度与页面复杂度平衡
- 维持“摘要 + 列表 + 单次详情 + 横向对比”四层结构，便于后续继续演进

### 7. 关键风险点
- 移动端宽度不足，需要支持横向滚动
- `summary` 某些字段可能缺失，需要统一兜底为 `0` 或 `-`
- 当前仍无前端自动化交互测试，只能用静态校验与 diff 检查兜底
