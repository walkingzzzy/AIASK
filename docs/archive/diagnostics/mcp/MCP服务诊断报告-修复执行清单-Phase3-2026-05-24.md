## 1. 数据回填运维方案

### 1.1 `scripts/backfill_p0_data.py` 使用方法

**全量回填**(运维谨慎,首次运行):
```bash
python scripts/backfill_p0_data.py --all --report-path reports/backfill_$(date +%Y%m%d).json
```

**单项回填**:
```bash
# P0-1: 北向资金 21 月 stale → backfill 2 年
python scripts/backfill_p0_data.py --north-fund

# P0-1: 融资融券 (margin_market_flow + margin_detail)
python scripts/backfill_p0_data.py --margin

# P0-1: 龙虎榜 30 个交易日
python scripts/backfill_p0_data.py --dragon-tiger

# P0-4: 向量索引 backfill
python scripts/backfill_p0_data.py --vector --limit 500

# P0-2: sh000001 错位映射诊断(只读)
python scripts/backfill_p0_data.py --diagnose-sh000001

# P2-4.1.1: db.stock_quotes 全市场预热
python scripts/backfill_p0_data.py --prewarm-quotes --prewarm-batch 200
```

**输出格式**:
- 每个步骤先打印 db 当前状态(行数 / max_date / days_stale)
- 调用 ExternalGapSyncService 等现有同步接口
- 完成后再次打印对比
- 任何异常不中断剩余步骤,最后输出汇总表
- `--report-path` 写 JSON 详细报告(运维归档)

**幂等性**:基于现有同步层的 `INSERT ... ON CONFLICT DO UPDATE` 语义,可重复运行。

### 1.2 sh000001 错位诊断逻辑

```python
# 脚本对比 stock_quotes 中 sh000001 / 000001 的 close 值
if abs(sh_close - pa_close) < 0.5:
```

诊断结果写入 JSON,运维可据此决定下一步:

### 3.3 isotonic 真校准(P2-4.3.1 落地 50%)

`tools/decision_helpers.py` 已增加:

```python
def _calibrate_buy_probability(
    score, confidence, style, volatility,
    *,
    historical_calibration: dict | None = None,  # 新参数
) -> float:
    # baseline logit 计算(向后兼容,不传 historical_calibration 时行为不变)
    raw_prob = ...

    # P2-4.3.1: 历史校准修正(若可用)
    if historical_calibration:
        calibrated = _apply_isotonic_calibration(raw_prob, historical_calibration)
        if calibrated is not None:
            return float(_clamp(calibrated, 0.0, 1.0))
    return raw_prob


def _apply_isotonic_calibration(raw_prob: float, history: dict) -> float | None:
    """sklearn IsotonicRegression 校准 raw_prob → calibrated_prob"""
    try:
        from sklearn.isotonic import IsotonicRegression
    except ImportError:
        return None  # graceful fallback

    pred = history.get("predicted_probs") or []
    actual = history.get("actual_hit_rates") or []
    if len(pred) < 30:
        return None  # 样本太少不校准

    iso = IsotonicRegression(out_of_bounds="clip", y_min=0.0, y_max=1.0)
    iso.fit(pred, actual)
    return float(iso.predict([raw_prob])[0])
```

**实测验证**(本轮 smoke):
- 无 historical_calibration → baseline `0.6162`
- 60 样本随机历史 → calibrated `0.4516`(真实修正了 ECE)
- sklearn 不可用 → 自动 fallback 到 baseline,**不抛异常**
