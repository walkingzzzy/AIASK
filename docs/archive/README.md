## 使用边界

1. 这些文档保留“当时如何判断”的证据，不保留“当前事实”的权威性。
2. 若归档文档中的结论要重新用于实施，必须先和当前代码、测试、运行时注册结果重新校准。
3. 如果某份归档文档重新成为当前入口，应迁回主路径并同步更新 [`../README.md`](../README.md) 或 [`../plans/README.md`](../plans/README.md)。
