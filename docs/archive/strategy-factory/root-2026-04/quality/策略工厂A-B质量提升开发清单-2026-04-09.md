目标：把策略工厂的优化重点从“提高 Gate-3 提交通过率”升级为“稳定提升原始 validation_grade 的 A/B 占比”，让更多候选在样本外稳健性上真正达标，而不是主要依赖门禁修正或宽松放行。

说明（2026-04-11 代码核对修订）：
- 本文中的 `[x]` 优先表示代码、接口、页面或测试证据已经落地。
- 本文中的运行结果类验收项，例如“连续 3 次真实 run 提升”“family 的 raw B 率显著提升”“strict/live 指标持续改善”，只有在默认真实 run 连续满足时才应勾选。
- 因此，本文保留了大量“机制已落地、结果仍待验收”的状态区分，避免把结构改造误写成结果已经稳定兑现。

## 一、当前判断

- [x] 当前主要瓶颈不是能不能跑通，而是原始 `validation_grade` 仍普遍偏低，很多候选停留在 `C/D`
- [x] 当前需要优先提升的是：
  - `oos_ic`
  - `oos_ir`
  - `stability`
  - `ci_significance`
  - `positive_ratio`
- [x] 当前需要避免把“Gate-3 过了”误判成“策略质量已经达到 A/B”

说明：
- 原始等级定义在 `packages/akshare-mcp/src/akshare_mcp/services/validation.py`
- `A >= 70`
- `B >= 55`
- `C >= 40`
- `D < 40`

截至 2026-04-11 的最新现实补充：

1. 默认工厂此前一度被 `readiness` 挡成 `skipped`，但最新默认真实 run `factory_run_1775875548_3aa36019` 已经恢复到 `success`，并出现 `raw={B:3,C:1}`；当前问题从“完全不产出”转成了“默认 steady-state 还要继续验证连续性”。
2. 当前整体真实 cohort 虽然已不再是“全 D”，但仍然明显 `D` 偏多：`A=6, B=16, C=30, D=348`，`raw_validation_b_rate=0.04`，`raw_b_or_above_rate=0.055`。
3. `momentum` 已经是目前最强的一条，部分桶位已经能稳定出现 `raw A/B`；`ma_cross` 虽然不再是 `raw B=0`，但主桶仍然偏弱；`quality_factor` 最新默认 run 已到 `raw C / 54`，而受控真实 run `factory_run_1775875771_deab672c` 已经打出 `raw A/B`，说明它不再是“完全打不起来”，而是“默认可复现性还不够”。
4. `strict_incubation_ready_rate=0.195` 说明严格孵化层已经有真实改善，`live_candidate_ready_rate=0.0075` 仍然偏低；但最新受控 `quality_factor` run 已经出现 `live_candidate_ready=true` 的真实样本，说明 live 侧已经从“完全为零”推进到了“局部可达成”。
5. 近期受控真实 run 已经证明 `momentum`、`ma_cross`、`quality_factor` 都能打出更好的样本，但还没有证明默认工厂在不放宽门控的情况下也能持续复现这些结果。
6. 因此，这份清单接下来的重点，不再是“让工厂能跑通”，而是“让默认工厂稳定产出，并把 raw B/A 与 live-ready 占比继续做高”。
