# 策略工厂 · 选股逻辑修复方案

> 日期：2026-05-15
> 目标：修复策略工厂选择新股/流动性差股票导致回测样本不足的问题
> 基于：代码审查 + 策略工厂实际运行结果分析 + 行业标准联网调研

---

## 0. 问题诊断

### 0.1 现象

策略工厂运行产出 37 个候选策略，但 **0 个通过 Gate-2 回测**。拒绝原因：

```
backtest_result.passed = False
reason_code = "insufficient_samples"
reason = "有效样本 2 小于要求 3"
skipped_codes = [{"code": "920045", "reason": "insufficient_klines", "available": 84}]
```

### 0.2 根本原因

Spawner 选择了 `['920185', '920045', '688981']` 作为目标股票：
- `920045`：北交所新股，只有 **84 根 K 线**（不足 500 根回测要求）
- `920185`：北交所新股
- `688981`：科创板

这些股票来自 `snapshot["factor_research"]["stock_family_allocation"]`，该字典由因子研究阶段的全市场评分产出。**没有任何过滤机制排除 K 线不足/流动性差的股票**。

### 0.3 选股流程（代码审查确认）

```
Path 1: Spawner 本地候选
  spawn(snapshot) → _apply_snapshot_target_alignment()
    → _snapshot_target_symbols(strategy_type, snapshot)
      → 从 stock_family_allocation 中按 priority 排序选 top N
      → ❌ 没有 K 线数量过滤
      → ❌ 没有流动性过滤
      → ❌ 没有排除北交所/次新股

Path 2: 全市场策略矩阵（StockStrategyMatrix）
  plan(db, snapshot) → load_stock_universe_rows()
    → _fetch_history_bar_counts() → 过滤 < 100 根 K 线的
    → ✅ 有 _MIN_HISTORY_BARS = 100 过滤
    → ❌ 但 100 根对回测仍然不够（需要 ≥ 250 根）
    → ❌ 没有流动性/市值过滤
```

**关键差距**：
- Path 1（Spawner）**完全没有过滤**
- Path 2（Matrix）有 100 根最低限制，但太低（回测需要 ≥ 250 根）
- 两条路径都没有排除北交所（920xxx）和流动性差的股票

## 1. 行业标准（联网调研）

### 1.1 "北京A股除外"是 A 股量化的行业共识

在同花顺 Supermind 量化策略平台上，**大量策略明确标注"北京A股除外"**作为基础筛选条件：

- "换手率3%-12%,前25天有涨停,**北京A股除外**"（[同花顺量化](https://quant.10jqka.com.cn/view/article/21722)）
- "换手率3%-12%,**剔除北京A股**,流通市值大于100亿元"（[同花顺量化](https://quant.10jqka.com.cn/view/article/21912)）
- "换手率3%-12%,**剔除北京A股**,现量大于1万手"（[同花顺量化](https://quant.10jqka.com.cn/view/article/21922)）

这说明**排除北交所是 A 股量化选股的行业惯例**，不是我们独创的规则。

### 1.2 最低历史数据要求

- 量化回测通常假设 252 个交易日 = 1 年（[Quant StackExchange](https://quant.stackexchange.com/questions/16611/here-is-an-approach-for-measuring-data-snooping-is-it-new)）
- 回测到实盘的衰减幅度通常在 20-50%（[LLMQuant/AlphaCrafter 研究](https://llmquant.substack.com/p/when-three-robots-trade-stocks-better)，已改写）：CSI 300 上 LSTM 回测 22.93% → 实盘 -7.74%；MACD 回测 20.35% → 实盘 -38.69%
- 这进一步说明**充足的历史数据（≥ 250 天）是回测有效性的基本前提**

### 1.3 流动性与市值门槛

- [QuantRocket](https://www.quantrocket.com/codeload/qval/qval/Part3-Interactive-Strategy-Development.ipynb.html)：选择市值 top 60% 的股票作为流动性筛选
- [Intellectia.ai 社区筛选器](https://intellectia.ai/community-screener-plaza/yes-us-market)：Market Cap ≥ $2B（约 140 亿人民币）
- A 股实践中，流通市值 > 100 亿是常见的大盘股筛选条件

## 2. 修复方案

### 2.1 PR-U1：Spawner 选股前置过滤（P0，核心）

**位置**：`packages/strategy-factory/src/strategy_factory/domain/spawner_parts/selection.py`

**问题**：`_snapshot_target_symbols()` 从 `stock_family_allocation` 选股时没有任何过滤。

**改动**：在 `_snapshot_target_symbols()` 返回结果前，加入过滤逻辑：

```python
@classmethod
def _is_tradable_target(cls, code: str) -> bool:
    """判断股票代码是否适合作为策略目标。"""
    c = str(code or "").strip()
    if not c:
        return False
    # 排除北交所（920xxx、8xxxxx）
    if c.startswith("920") or c.startswith("8"):
        return False
    # 排除 B 股（200xxx、900xxx）
    if c.startswith("200") or c.startswith("900"):
        return False
    return True
```

在 `_snapshot_target_symbols()` 的 `ranked_matches` 过滤后加入：

```python
# 过滤不适合的股票
ranked_matches = [
    (score, code) for score, code in ranked_matches
    if cls._is_tradable_target(code)
]
```

### 2.2 PR-U2：全市场矩阵提高最低 K 线门槛（P0）

**位置**：`packages/strategy-factory/src/strategy_factory/application/stock_strategy_matrix_parts/normalizers.py`

**问题**：`_MIN_HISTORY_BARS = 100` 太低，回测需要至少 250 根。

**改动**：

```python
_MIN_HISTORY_BARS = 250  # 从 100 提高到 250（至少 1 年数据）
```

### 2.3 PR-U3：stock_family_allocation 生成时排除不合格股票（P0）

**位置**：`packages/strategy-factory/src/strategy_factory/application/research/_research_build_steps.py` 或 `factor_research_builder.py` 中生成 `stock_family_allocation` 的逻辑。

**问题**：全市场评分时没有排除北交所/次新股/流动性差的股票。

**改动**：在 `_load_stock_family_allocation()` 中加入过滤：

```python
# 排除不适合做策略目标的股票
_EXCLUDED_CODE_PREFIXES = ("920", "8", "200", "900")

def _is_eligible_for_allocation(code: str, row: dict) -> bool:
    """判断股票是否有资格进入 stock_family_allocation。"""
    c = str(code or "").strip()
    if not c:
        return False
    # 排除北交所、B 股
    if any(c.startswith(prefix) for prefix in _EXCLUDED_CODE_PREFIXES):
        return False
    # 排除市值过小（< 20 亿）
    market_cap = float(row.get("market_cap") or 0)
    if 0 < market_cap < 20:  # stocks 表中 market_cap 单位是亿
        return False
    return True
```

### 2.4 PR-U4：Runner 层 K 线数量二次验证（P0）

**位置**：`packages/strategy-factory/src/strategy_factory/application/research/runner.py`

**问题**：`_sanitize_local_spawn_targets()` 已有 K 线检查（`_GATE_1_MIN_KLINES = 30`），但门槛太低。

**改动**：提高门槛到 250：

```python
_GATE_1_MIN_KLINES = 250  # 从 30 提高到 250
```

### 2.5 PR-U5：list_stock_universe 默认排除北交所（P1）

**位置**：`packages/akshare-mcp/src/akshare_mcp/storage/sqlite/stock_info.py`

**问题**：`list_stock_universe()` 返回全部股票，包括北交所。

**改动**：在 SQL 中默认排除北交所代码：

```python
# 默认排除北交所（920xxx）和 B 股（200xxx、900xxx）
conditions.append(
    f"{code_col} NOT LIKE '920%' AND {code_col} NOT LIKE '200%' AND {code_col} NOT LIKE '900%'"
)
```

### 2.6 PR-U6：全市场评分增加流动性权重（P1）

**位置**：`stock_strategy_matrix_parts/policy.py` 中的 `_row_priority_components()`

**问题**：当前评分只考虑市值、估值、因子对齐、板块热度，没有流动性权重。

**改动**：在评分中加入流动性分（基于 `kline_1d` 的近 20 日平均成交额）：

```python
# 流动性分：日均成交额越高越好（对数标准化）
avg_amount_20d = float(row.get("avg_amount_20d") or 0)
if avg_amount_20d > 0:
    import math
    liquidity_score = min(1.0, math.log10(max(avg_amount_20d, 1)) / 9.0)  # 10亿=1.0
else:
    liquidity_score = 0.0
```

## 4. 预期效果

| 指标 | 当前 | 修复后 |
|---|---|---|
| 目标股票 K 线充足率 | ~67%（3 只中 2 只够） | **100%**（全部 ≥ 250 根） |
| 北交所股票进入候选 | 是 | **否** |
| 回测 insufficient_samples 拒绝率 | ~100% | **< 10%** |
| 策略通过 Gate-2 比例 | 0% | **预计 > 50%** |

### 4.1 排除规则汇总

| 排除条件 | 代码前缀 | 原因 |
|---|---|---|
| 北交所 | 920xxx | 流动性极差，日均成交额 < 100 万 |
| 北交所老三板 | 8xxxxx | 已退市/暂停交易 |
| B 股 | 200xxx、900xxx | 外币计价，不适合 A 股策略 |
| 次新股 | K 线 < 250 根 | 数据不足，价格异常 |
| 微型股 | 市值 < 20 亿 | 流动性差，冲击成本高 |

### 4.2 保留的股票池

修复后的有效股票池约为：
- 全 A 股 5,515 只
- 排除北交所 ~200 只
- 排除 B 股 ~100 只
- 排除 K 线不足 ~300 只
- 排除微型股 ~500 只
- **有效池 ≈ 4,400 只**

这个规模完全满足策略工厂的需求（每次只选 3-12 只目标股票）。

## 5. 与已有系统的关系

```
修复前：
全市场 5,515 只 → stock_family_allocation（含北交所新股）
    → Spawner 选 top 3（可能全是新股）
    → 回测 insufficient_samples → 全部拒绝

修复后：
全市场 5,515 只 → 排除北交所/B股/次新/微型 → 有效池 ~4,400 只
    → stock_family_allocation（只含合格股票）
    → Spawner 选 top 3（全部有 ≥ 250 根 K 线）
    → 回测正常执行 → Gate-3 评估命中率/利润因子
```
