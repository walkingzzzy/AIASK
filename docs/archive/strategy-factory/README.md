## 使用边界

1. 这些文档保留“当时如何分析、如何规划”的上下文，不保留“当前代码已按文中全部落地”的权威性。
2. 若归档文档中的结论要重新投入实施，必须先和当前源码、测试和运行时基线重新校准。
3. 当前若新增策略工厂文档，默认不要再放回 `策略工厂/` 或 `docs/plans/` 顶层，除非它确实是现行入口文档。
