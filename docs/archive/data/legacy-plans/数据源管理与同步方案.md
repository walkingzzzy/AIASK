# 数据源管理与同步方案

> 目标：在应用端建立完整的数据源管理体系，包括数据源配置、连接测试、数据库同步状态监控、一键同步、向量数据库处理，并在前端提供可视化管理界面。

---

## 一、现状分析

### 1.1 已有基础设施

| 组件 | 位置 | 功能 |
|---|---|---|
| `DataSourceManager` | `akshare_mcp/data_source/` | 统一数据获取层（Tushare → eFinance → Baostock） |
| `DataSyncService` | `akshare_mcp/services/data_sync.py` | 异步队列写入 SQLite + 重试 + 死信队列 |
| `DataSyncScheduler` | `akshare_mcp/services/data_sync_scheduler.py` | 后台定时同步（启动 + 每日 15:30） |
| `data_sync_manager` | `akshare_mcp/tools/managers/` | MCP 工具层（按需触发同步） |
| `VectorSearchEngine` | `akshare_mcp/services/vector_search.py` | 内存向量搜索（numpy） |
| `StrategyVectorPlatform` | `akshare_mcp/services/vector_platform.py` | 策略向量画像 + 持久化索引 |
| `StrategyTextEmbeddingService` | `akshare_mcp/services/text_embedding.py` | 文本嵌入（OpenAI/Ollama/本地） |
| `ConnectorsPanel` | `desktop/src/features/connectors/` | 前端连接器状态面板 |
| Finance MCP Servers | `packages/finance-mcp-servers/` | 通达信/同花顺/东方财富/QMT 连接器 |

### 1.2 当前缺失

| 缺失项 | 影响 |
|---|---|
| 无统一数据源注册表 | 无法动态添加/移除数据源 |
| 无连接测试 API | 无法验证数据源是否可用 |
| 无前端同步状态面板 | 用户无法看到同步进度和健康状态 |
| 无一键全量同步按钮 | 需要手动调用 MCP 工具 |
| 北向资金/融资融券无 DB 持久化 | 策略工厂 collect 阶段数据不完整 |
| 向量数据库无管理界面 | 无法查看索引状态和触发重建 |

## 三、数据源注册表

### 3.1 数据源类型定义

```python
@dataclass
class DataSourceConfig:
    id: str                    # 唯一标识 (如 "akshare", "tushare", "eastmoney")
    name: str                  # 显示名称
    type: str                  # "market_data" / "fund_flow" / "financial" / "news"
    provider: str              # "akshare" / "tushare" / "efinance" / "mcp_server"
    enabled: bool              # 是否启用
    priority: int              # 优先级（越小越优先）
    capabilities: list[str]    # 支持的数据类型 ["kline", "realtime", "north_fund", ...]
    env_keys: list[str]        # 需要的环境变量
    health_check_interval: int # 健康检查间隔（秒）
    last_check_time: str       # 最后检查时间
    last_check_status: str     # "healthy" / "degraded" / "unavailable"
    error_message: str         # 最后错误信息
```

### 3.2 内置数据源

| ID | 名称 | 类型 | 能力 | 环境变量 |
|---|---|---|---|---|
| `akshare` | AKShare 开源 | market_data | kline, north_fund, margin, sector_flow | 无（免费） |
| `tushare` | Tushare Pro | market_data | kline, financial, index, calendar | `TUSHARE_TOKEN` |
| `eastmoney` | 东方财富 | market_data | realtime, kline, fund, news | `EM_API_TOKEN`（可选） |
| `tongdaxin` | 通达信 | trading | realtime, order, position | `TDX_PATH` |
| `tonghuashun` | 同花顺 | trading | order, position, account | `THS_TOKEN` |
| `qmt` | QMT 量化 | trading | order, position, algo | `QMT_PATH` |
| `baostock` | BaoStock | market_data | kline, financial | 无（免费） |

## 六、数据同步增强

### 6.1 新增持久化方法（解决 collect 阶段数据缺失）

需要在 SQLite schema 中新增表：

```sql
-- 北向资金历史
CREATE TABLE IF NOT EXISTS north_fund_history (
    date TEXT NOT NULL,
    net_buy REAL,
    buy_amount REAL,
    sell_amount REAL,
    cumulative_net REAL,
    source TEXT DEFAULT 'akshare',
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (date)
);

-- 融资融券汇总
CREATE TABLE IF NOT EXISTS margin_summary (
    date TEXT NOT NULL,
    margin_balance REAL,
    margin_buy REAL,
    short_balance REAL,
    margin_balance_change_5d REAL,
    source TEXT DEFAULT 'akshare',
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (date)
);

-- 板块资金流向
CREATE TABLE IF NOT EXISTS sector_fund_flow (
    date TEXT NOT NULL,
    sector_name TEXT NOT NULL,
    net_inflow REAL,
    rank_position INTEGER,
    source TEXT DEFAULT 'akshare',
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP,
    PRIMARY KEY (date, sector_name)
);
```

## 七、向量数据库处理流程

### 7.1 向量化流水线

```
原始数据 → 特征提取 → 向量化 → 索引构建 → 持久化
    │           │          │          │          │
    │           │          │          │          └── SQLite vector 表
    │           │          │          └── numpy index + 磁盘缓存
    │           │          └── text_embedding / 数值向量化
    │           └── K线形态 / 策略参数 / 文本摘要
    └── kline_1d / strategies / market_docs
```

### 7.2 支持的向量化类型

| 类型 | 输入 | 方法 | 维度 | 用途 |
|---|---|---|---|---|
| K线形态 | 60日收益率序列 | returns 标准化 | 60 | 相似K线搜索 |
| 策略画像 | 策略参数+指标 | 数值拼接 | ~30 | 策略去重 |
| 文本语义 | 策略描述/新闻 | text-embedding-3 | 1536 | 语义搜索 |
| 因子暴露 | 因子值序列 | 标准化 | 因子数 | 因子相似度 |

### 7.3 一键向量重建

```python
# POST /v1/vector/rebuild {"collection": "all"}
async def rebuild_all_vectors():
    # 1. K线形态向量（从 kline_1d 表）
    await vector_backfill_kline_patterns(window=60, universe=REPRESENTATIVE_STOCKS)
    
    # 2. 策略画像向量（从 strategies 表）
    await vector_backfill_strategy_profiles()
    
    # 3. 市场文档向量（从 market_docs 表）
    await vector_backfill_market_docs()
    
    # 4. 构建统一快照
    await vector_build_snapshot()
    
    # 5. 运行 benchmark 验证
    await vector_benchmark_collection()
```

## 十一、数据源分类（免费 vs 付费）

### 11.1 完全免费数据源

| 数据源 | Python 库 | 数据范围 | 频率限制 | 适用场景 |
|---|---|---|---|---|
| **AKShare** | `akshare` | A股/港股/美股/期货/基金/宏观/北向/融资融券/板块资金 | 无硬性限制（建议间隔 0.5s） | **主力数据源**，覆盖最全 |
| **BaoStock** | `baostock` | A股日/周/月/5分钟 K 线 + 财务 + 除权 | 无限制 | 历史 K 线回填 |
| **eFinance** | `efinance` | 东方财富实时行情/K线/基金/债券/期货 | 无限制 | 实时行情备选 |
| **Ashare** | `Ashare` | 新浪/腾讯实时行情 | 无限制 | 超低延迟实时行情 |
| **EasyQuotation** | `easyquotation` | 新浪/腾讯全市场实时行情 | 无限制（200ms 全市场） | 盘中实时监控 |
| **QStock** | `qstock` | A股行情/财务/资金流/龙虎榜 | 无限制 | AKShare 备选 |
