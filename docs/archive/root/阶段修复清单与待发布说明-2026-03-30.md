# 阶段修复清单与待发布说明（2026-03-30）

## 一、本阶段完成的修复

### 1. MCP 原生能力补齐

- 为 `akshare-mcp` 注册了原生 MCP `Resources` 与 `Prompts`，使运行时能力声明与 SDK 层实现保持一致。
- 新增资源注册与实现：
  - `packages/akshare-mcp/src/akshare_mcp/resources/__init__.py`
  - `packages/akshare-mcp/src/akshare_mcp/resources/stock_and_watchlist.py`
  - `packages/akshare-mcp/src/akshare_mcp/resources/strategy.py`
- 新增 Prompt 注册与实现：
  - `packages/akshare-mcp/src/akshare_mcp/prompts/__init__.py`
  - `packages/akshare-mcp/src/akshare_mcp/prompts/analysis.py`
- 资源 / Prompt 已在 `packages/akshare-mcp/src/akshare_mcp/server.py` 中注册。

### 2. `execution_manager` 状态收敛

- 将 `execution_manager` 从“进程内任务状态”收敛为“内存缓存 + artifact registry 持久化”。
- 软闸门运行时配置也已持久化，可跨进程恢复。
- `list` / `summary` / `update` 相关流程支持从 artifact 恢复任务。
- 相关文件：
  - `packages/akshare-mcp/src/akshare_mcp/tools/managers/execution_manager.py`
  - `apps/bff/src/mcp-gateway/mcp-gateway.service.ts`

### 3. `alerts_manager` DB-first 收敛

- `alerts_manager` 的 `list` / `check` / `update` / `delete` 已改为以 DB 为 source of truth。
- `_alerts_store` 不再作为真实性来源，仅作为进程内缓存和降级回退。
- `check` 会以 DB 中 active alerts 为基准重新装载告警。
- `update` / `delete` 已支持通过 DB 重新定位告警，不再假设必须命中同一进程内缓存。
- 相关文件：
  - `packages/akshare-mcp/src/akshare_mcp/tools/managers/alerts_manager.py`
  - `apps/bff/src/mcp-gateway/mcp-gateway.service.ts`

### 4. `tool-only` 启动路径真正轻量化

- 将 `server.py` 的工具注册流程抽离为按 startup profile 的分层注册。
- `full` profile 保留完整工具集。
- `tool-only` profile 仅注册核心轻量工具与必要 managers，跳过以下重型模块：
  - `vector`
  - `skills`
  - `quant`
  - `sentiment`
  - `data_sync`
  - `factor_profile`
- 对应重型 managers 在 `tool-only` 下也会跳过：
  - `vector_search_manager`
  - `quant_manager`
  - `sentiment_manager`
  - `data_sync_manager`
- 同时保留了 scheduler getter 的懒加载兼容层，避免破坏既有测试与调用方式。
- 相关文件：
  - `packages/akshare-mcp/src/akshare_mcp/server.py`

### 5. 历史回归兼容性修复

- 恢复 `portfolio_manager` 顶层 `updates` 参数兼容。
- 恢复 `sector_manager` 顶层 `days` / `period` 参数兼容，并修复内部递归调用的参数传递方式。
- 相关文件：
  - `packages/akshare-mcp/src/akshare_mcp/tools/managers/portfolio_manager.py`
  - `packages/akshare-mcp/src/akshare_mcp/tools/managers/sector_manager.py`
