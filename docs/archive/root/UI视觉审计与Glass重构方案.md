### 0.2 与 2026-03-28 版本相比的核心变化

1. **登录页** 已升级为双栏玻璃布局，左侧功能说明 + 右侧表单，整体更有入口仪式感，但左侧卡片底色仍偏不透明。

### 0.3 最需要优先解决的 3 个问题

1. **中央画布被压缩**：三栏壳层（侧栏 + 主内容 + AI Dock）同时展开时，主内容区有效宽度约为 860-920px，对于需要展示图表的行情、绩效、执行页非常不友好。
2. **Glass 仅限首屏**：所有有玻璃效果的页面，glass 只出现在 Hero 区，点击内容向下滚动后立即回到白卡体系，造成强烈的"上段新产品、下段旧后台"割裂感。
3. **空状态过多**：行情主图（K线暂无）、首页自选股（还没有自选股）、绩效净值曲线（暂无数据）等空状态占据了大量主屏空间，但没有设计到位的空状态插画和引导动作，显得功能未完成。

## 2. 总体结论

### 2.1 当前产品的主要问题不是“难看”，而是“过于单一”

当前界面已经具备较统一的中性浅色基底、较规整的圆角与轻边框，但几乎所有页面都落在同一种“白卡片 + 浅灰背景 + 细边框 + 小阴影”的表达上。结果是：

- 首页、研究页、策略页、后台页之间的产品气质差异很弱。
- 绝大多数容器拥有近似的视觉权重，导致用户很难一眼看出主区域、次区域、辅助区域。
- 页面虽然“干净”，但缺少真正的层次、空气感和现代桌面工作台的材质变化。

### 2.2 项目并非完全没有玻璃感，但玻璃语言没有形成系统

代码里已经存在 `--color-glass`、`glass`、`glass-strong`、`backdrop-blur-xl` 等定义和用法，但当前实际视觉效果更接近“半透明白面板”，而不是可感知的 Glassmorphism：

- `apps/web/app/globals.css` 中的玻璃色值透明度过高，接近实心白。
- `AppShell` 顶栏与右侧 Dock 使用了 `backdrop-blur`，但主内容区几乎都是实体白卡。
- `performance` 与 `execution` 页首屏已经开始尝试径向渐变 + blur，但只停留在局部英雄区，无法带动全站视觉升级。

用户感知上的“缺乏毛玻璃”其实是“玻璃材质没有成为页面骨架的一部分”。

### 2.3 三栏壳层长期压缩中央画布，放大了卡片单一感

多数页面同时存在：

- 左侧功能式导航
- 中央主画布
- 右侧固定 AI 工作台

在桌面 1440px 宽度下，中央核心内容被持续挤压。很多页面的主内容只剩一条中等宽度白色画布，视觉上既不通透，也不够沉浸，尤其影响：

- 首页
- 行情页
- 个股详情页
- 执行 / 绩效页
- 设置与后台页

### 2.4 圆角已经不少，但“柔和感”没有被真正建立起来

很多页面已使用 `18px`、`22px`、`24px` 以上圆角，但由于：

- 背景是近乎纯白
- 容器之间间距偏紧
- 阴影偏浅且大面积缺失
- 缺少背景层和透明层的衬托

所以圆角只是“组件参数”，没有转化成真正的材质柔和感。

### 2.5 深度表达明显不足

当前深度主要来自：

- 细边框
- 很轻的 `shadow-sm`
- 少量 inset highlight

缺失的是：

- 前景玻璃与背景氛围层的分离
- 中层容器与顶层浮层之间的阶梯
- 重要模块 hover / focus 时的深度变化
- 图表、表格、筛选器、摘要区之间的空间前后关系

### 2.6 页面里最接近目标方向的是执行页与绩效页，但还不够完整

`/execution` 和 `/performance` 已经出现：

- 径向渐变
- 白色半透明面板
- 较大的圆角
- `backdrop-blur-xl`

这说明方向是可行的，但当前只在首屏英雄区生效，下面又回到常规白卡系统，造成“上半段像新产品，下半段像旧后台”。

## 3. 全局重构方向

## 3.1 设计目标

把 AIASK 从“统一白卡后台”升级为“带有轻金融科技质感的现代投研工作台”。

关键词：

- 更强主次层级
- 更有空气感的容器呼吸
- 克制但明确的玻璃材质
- 按场景分层，而不是全站一把刷
- 图表、过滤器、摘要、操作区之间有真正的前后关系

## 3.2 推荐的 Glassmorphism 基底

建议新增以下全局 token，并把现有 `glass` 类升级成真正可感知的玻璃层级。

```css
:root {
  --bg-app: #edf3f9;
  --bg-app-gradient:
    radial-gradient(circle at 8% 10%, rgba(103, 164, 255, 0.16), transparent 28%),
    radial-gradient(circle at 92% 14%, rgba(87, 210, 255, 0.12), transparent 24%),
    radial-gradient(circle at 48% 100%, rgba(255, 210, 118, 0.10), transparent 22%),
    linear-gradient(180deg, #f4f8fc 0%, #edf3f9 100%);

  --glass-bg: rgba(255, 255, 255, 0.22);
  --glass-bg-strong: rgba(255, 255, 255, 0.34);
  --glass-bg-soft: rgba(255, 255, 255, 0.14);
  --glass-border: rgba(255, 255, 255, 0.38);
  --glass-border-strong: rgba(208, 226, 248, 0.82);
  --glass-shadow: 0 24px 64px -32px rgba(23, 53, 93, 0.38);
  --glass-shadow-hover: 0 32px 88px -36px rgba(23, 53, 93, 0.46);
  --glass-blur: 18px;
  --glass-saturate: 180%;
}

.glass-panel {
  background:
    linear-gradient(135deg, rgba(255, 255, 255, 0.34), rgba(255, 255, 255, 0.18));
  border: 1px solid var(--glass-border);
  box-shadow: var(--glass-shadow), inset 0 1px 0 rgba(255, 255, 255, 0.46);
  backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-saturate));
  -webkit-backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-saturate));
}

.glass-panel-strong {
  background:
    linear-gradient(135deg, rgba(255, 255, 255, 0.46), rgba(255, 255, 255, 0.24));
  border: 1px solid var(--glass-border-strong);
  box-shadow: var(--glass-shadow-hover), inset 0 1px 0 rgba(255, 255, 255, 0.62);
  backdrop-filter: blur(22px) saturate(190%);
  -webkit-backdrop-filter: blur(22px) saturate(190%);
}

.glass-hover {
  transition: transform 180ms ease, box-shadow 180ms ease, border-color 180ms ease;
}

.glass-hover:hover {
  transform: translateY(-2px);
  box-shadow: var(--glass-shadow-hover), inset 0 1px 0 rgba(255, 255, 255, 0.62);
  border-color: rgba(116, 181, 255, 0.48);
}
```

### 3.3 毛玻璃使用边界

不建议把所有卡片都做成毛玻璃。正确做法是分层使用：

- 一级玻璃：顶栏、页面 Hero、浮动筛选器、工作区摘要、右侧 Dock、模态框
- 二级玻璃：关键 KPI 区、图表外框、策略 / 执行摘要卡
- 实体容器：高密度表格、长表单、审计日志、后台数据表
- 纯色容器：告警、风险、空状态、占位区域

## 3.4 容器与布局统一策略

建议统一容器节奏，不再让所有模块都卡在 `p-4` 到 `p-5`：

- 页面级容器：`padding` 从 `24px/28px` 提升到 `32px/36px`
- 核心 Hero：`padding` 建议 `28px-36px`
- 面板间距：普通模块 `gap: 20px`，主区块 `gap: 24px-32px`
- 主卡圆角：从 `18/22/24px` 统一拉升到 `24/28/32px`
- 密集表格区：保留 `16-20px` 圆角，避免过度软化数据密度

推荐建立三个容器等级：

- `panel-solid`：高密度白底实体卡
- `panel-glass`：关键摘要与过滤面板
- `panel-hero`：页面首屏大模块

## 3.5 视觉增强建议

### 3.5.1 渐变与背景氛围

- 页面背景不再纯灰平刷底，应使用低对比度径向氛围层。
- 不同工作流使用不同氛围色：
  - 看盘：蓝青
  - 研究：蓝绿
  - 策略：蓝靛
  - 交易 / 风险：蓝灰 + 橙红
  - 管理：石板蓝

### 3.5.2 图标系统

- 现有文本缩写图标（如 `MK`、`RS`、`ST`）信息识别度有限。
- 建议引入统一线性图标系统，大小统一为 `16/18/20px`。
- 一级导航、页面标签、状态卡、空状态插画统一图标语言。

### 3.5.3 微交互

- 卡片 hover：轻微上浮 `translateY(-2px)` + 阴影加深
- 筛选 chip：选中时增加柔和渐变底与高光边框
- 表格行 hover：从纯色 hover 改为浅玻璃投影或高亮边
- 图表切换：用 `opacity + blur` 的 160ms 过渡替代直接跳变
- Dock 抽拉：增加阻尼过渡，让右侧 AI 区真正像“玻璃抽屉”

## 6. 结论与执行建议

### 6.1 这轮改造不建议只改颜色，必须同时改三件事

- 壳层：先处理 `AppShell` 的左中右空间关系，把中央画布“放出来”
- 材质：建立真正分层的玻璃体系，而不是继续堆纯白卡
- 节奏：把 `padding / gap / radius / shadow` 拉开，做出呼吸感和主次感

### 6.2 推荐的落地顺序

1. 重构 `globals.css` 中的背景、glass token、阴影与圆角分级。
2. 重构 `components/app-shell.tsx`，把顶栏、侧栏、Dock 与主画布的层级重新梳理。
3. 先改首页、行情、个股、策略超市、执行、绩效六个高频页面。
4. 再把登录 / 设置 / 后台页跟上新的材质系统。
5. 最后统一长列表和长表单类页面，完成全站一致性收口。

### 6.3 最关键的设计判断

AIASK 需要的不是夸张的炫技玻璃，而是“克制、可信、可分层”的玻璃工作台。

如果下一轮只把卡片透明度调低、加大 blur，而不改变：

- 页面主次结构
- 三栏空间关系
- 容器呼吸感
- 页面主题氛围

那么最终结果只会是“半透明的旧后台”，不会是新的产品体验。

## 9. 设计原则备忘

> 给未来接手改造的开发者的判断参考。

1. **Glass 不等于透明**：只降低不透明度而不改变背景氛围，结果只是"模糊的白卡"。Glass 效果的核心是：**背景有足够丰富的颜色层，前景面板用 blur 穿透并混合它**。
2. **每个页面只需要一个真正的 Hero**：不要把所有卡片都做成 glass-hero，Hero 只应占首屏，之后进入轻玻璃和实体卡的分层结构。
3. **白卡不是错误，是次级层**：高密度数据表格、审计日志、长表单保持 `surface-card` 是正确的，它们是数据密度的承载体，不需要玻璃化。
4. **空状态是入口，不是占位符**：每个空状态都应该有清晰的行动按钮，引导用户进入下一步工作流，而不是让用户面对空白等待数据。
5. **三栏壳层是核心矛盾**：侧栏 + 主内容 + AI Dock 三栏同时展开时，中央可用宽度约 820-900px，对行情图表等宽度敏感的内容极不友好。最根本的解法是允许用户折叠任意侧栏。
