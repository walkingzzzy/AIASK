# 自选股/自定义板块概述

> 原始URL: https://help.tdx.com.cn/quant/docs/markdown/mindoc-1h139a4ckchkk/
> 抓取时间: 2026-02-03

自选股/自定义板块API提供创建、管理自定义板块及其成份股的功能。

## 函数列表

| 函数名 | 说明 |
|--------|------|
| [get_user_sector](./get_user_sector.md) | 获取自定义板块列表 |
| [create_sector](./create_sector.md) | 创建自定义板块 |
| [delete_sector](./delete_sector.md) | 删除自定义板块 |
| [rename_sector](./rename_sector.md) | 重命名自定义板块 |
| [send_user_block](./send_user_block.md) | 添加自定义板块成份股 |
| [clear_sector](./clear_sector.md) | 清空自定义板块成份股 |
