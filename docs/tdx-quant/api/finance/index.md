# 财务类数据概述

> 原始URL: https://help.tdx.com.cn/quant/docs/markdown/TdxQuant.md/
> 抓取时间: 2026-02-03

财务类数据API提供上市公司财务报表数据、股票交易数据、板块交易数据等功能。

## 函数列表

| 函数名 | 说明 |
|--------|------|
| [get_financial_data](./get_financial_data.md) | 获取专业财务数据 |
| [get_financial_data_by_date](./get_financial_data_by_date.md) | 获取指定日期财务数据 |
| [get_gpjy_value](./get_gpjy_value.md) | 获取股票交易数据 |
| [get_gpjy_value_by_date](./get_gpjy_value_by_date.md) | 获取指定日期股票交易数据 |
| [get_bkjy_value](./get_bkjy_value.md) | 获取板块交易数据 |
| [get_bkjy_value_by_date](./get_bkjy_value_by_date.md) | 获取指定日期板块交易数据 |
| [get_scjy_value](./get_scjy_value.md) | 获取市场交易数据 |
| [get_scjy_value_by_date](./get_scjy_value_by_date.md) | 获取指定日期市场交易数据 |
| [get_gp_one_data](./get_gp_one_data.md) | 获取股票的单个数据(非序列) |
