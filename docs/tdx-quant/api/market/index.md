# 行情类信息概述

> 原始URL: https://help.tdx.com.cn/quant/docs/markdown/mindoc-1ctuhthaq5qmg/
> 抓取时间: 2026-02-03

行情类信息API提供股票、基金、期货等金融产品的行情数据获取功能。

## 函数列表

| 函数名 | 说明 |
|--------|------|
| [get_market_data](./get_market_data.md) | 获取K线数据 |
| [get_market_snapshot](./get_market_snapshot.md) | 获取快照数据 |
| [get_stock_info](./get_stock_info.md) | 获取证券基本信息 |
| [get_divid_factors](./get_divid_factors.md) | 获取分红配送数据 |
| [get_ipo_info](./get_ipo_info.md) | 获取新股申购信息 |
| [get_more_info](./get_more_info.md) | 获取股票更多信息 |
| [get_gb_info](./get_gb_info.md) | 获取每天的股本数据 |
