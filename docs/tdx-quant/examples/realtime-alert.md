# 订阅行情涨幅突破实时预警

> 原始URL: https://help.tdx.com.cn/quant/docs/markdown/mindoc-1h1525ci3mnkc/mindoc-1h1526nmnk5n4.html
> 抓取时间: 2026-02-03

## 功能说明

本示例演示如何订阅板块成分股行情，当涨幅突破阈值时发送实时预警到客户端。

## 核心功能

1. **动态获取监控股票**：从指定板块获取有效股票代码列表
2. **分批订阅行情**：避免单次订阅过多，分批进行订阅
3. **实时涨幅监控**：监控股票涨幅，突破阈值时触发预警
4. **防抖机制**：避免短时间内重复触发预警
5. **首次触发后取消订阅**：股票首次触发预警后自动取消订阅

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| SECTOR_NAMES | 监控板块列表 | ['通达信88'] |
| PRICE_RISE_THRESHOLD | 涨幅阈值 | 5.0% |
| ANTI_SHAKE_SECONDS | 防抖间隔 | 10秒 |
| BATCH_SUBSCRIBE_SIZE | 分批订阅大小 | 50只/批 |

## 关键API

| API | 说明 |
|-----|------|
| `subscribe_hq()` | 订阅行情实时更新 |
| `unsubscribe_hq()` | 取消订阅 |
| `get_full_tick()` | 获取完整tick数据 |
| `send_warn()` | 发送预警信号到客户端 |

## 运行效果

- 程序启动后持续监控指定板块股票
- 当股票涨幅突破阈值时，在通达信终端显示预警信息
- 按 Ctrl+C 可安全退出程序
