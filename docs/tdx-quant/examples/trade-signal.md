# 计算调仓信号并快速买卖

> 原始URL: https://help.tdx.com.cn/quant/docs/markdown/mindoc-1h1525ci3mnkc/mindoc-1h1ep1rl20jv8.html
> 抓取时间: 2026-02-03

## 功能说明

本示例演示如何计算调仓信号并执行快速买卖操作。

## 核心功能

1. **信号计算**：基于技术指标或自定义条件计算买卖信号
2. **调仓决策**：根据信号决定买入、卖出或持仓
3. **快速执行**：通过API快速执行交易指令

## 关键API

| API | 说明 |
|-----|------|
| `get_market_data()` | 获取K线数据 |
| `get_market_snapshot()` | 获取最新行情快照 |
| `formula_zb()` | 调用技术指标公式 |

## 注意事项

- 实盘交易需要连接券商交易系统
- 建议先在模拟环境中测试策略
- 注意风险控制和资金管理
