## 整理规则

- 如果文档是长期协作约定、全仓入口规范，保留在根目录。
- 如果文档是某一专题的实施细则、阶段性方案、完成度报告或运行报告，优先放进对应 `docs/` 子目录。
- 如果文档已经被现状文档明确声明“必须在根目录保留”，后续移动前必须先同步修正所有引用口径。
