**修复建议**:
1. **立即**: 排查 `market_sentiment_context.index_context` 数据源,统一到 `macro_manager.market_overview` 或 `get_index_quote`
2. **短期**: 添加 `numeric_sanity` 检查 — 上证指数 close 在 [1000, 10000] 区间外强制 quality_gate.fail
3. **中期**: 所有指数级数据走专用 `db.index_quotes` 表,与个股 `db.stock_quotes` 完全分离

## 9. AI Agent 使用 MCP 服务的最佳实践建议

基于 22 场景实测,给 AI Agent 调用 MCP 时的建议:

### 9.1 优先调用 robust 工具

**首选(直接信任)**:
- `available_tools` / `get_available_categories` / `get_tool_contract` — 工具发现层 robust
- `compliance_manager.check_order` — 合规护栏 robust
- `live_trading_manager.submit_order` 4 层护栏 — 实盘安全 robust
- `data_validation` GE — 累计 14 场景 70/70 stable
- `portfolio_manager` CRUD / `paper_trading_manager.order_events` — 状态管理 robust

**次选(配合 source_chain 验证)**:
- `should_i_buy` / `should_i_sell` — 决策推理完整,但概率校准差(关注 ECE)
- `analyze_stock_workflow` / `analyze_stock_product_workflow` — 工作流编排 robust
- `build_stock_context` / `build_quant_context` / `build_event_context` — 上下文 builder 完整

**警惕(需 cross-tool reconciliation)**:
- `decision_manager.analyze` — score_penalty=8 单工具 sell 不可信,要 cross 5 个 decision 工具
- `dcf_valuation` / `scenario_dcf_valuation` / `ddm_valuation` / `fundamental_analysis_manager.intrinsic_value` — 5 估值器跨度 8× 必须 cross
- `research_manager` — 优先用 `analyze_research_report / get_research_summary / search_research_db / get_research_reports`

**最后兜底(已知降级)**:
- `get_realtime_quote(ETF)` — validate 拒绝,改用 `get_batch_quotes`
- `get_north_fund` — 21 月 stale,改用 `get_north_fund_top` / `get_north_fund_holding`
- `get_index_quote(000001/000300)` — 三源全跪,改用 `macro_manager.market_overview` / `get_realtime_quote(000016)`

### 9.2 必须读的字段

每次工具调用,AI 都应该至少看:

1. `success`(true/false)
2. `quality_flags`(是否含 fallback / partial / degraded / stale / empty)
3. `fallback_used`(true 时不可全信)
4. `fallback_reason`(具体哪条降级链失败)
5. `source_chain` / `backend_used`(数据真实来源)
6. `quality_gate.checks.freshness_sla.passed`(数据时效性)
7. `quality_gate.checks.fallback_degraded_flag.severity`(降级严重度)
8. `data_timestamp` / `freshness_sec`(数据时间)
9. `meta.lineage.run_id` / `trace_id`(可追溯)

### 9.3 cross-tool reconciliation 自检模板

AI Agent 在做关键决策(buy/sell)前应当:

1. **PE/PB 一致性**: 调用 `get_valuation_metrics` + `build_stock_context.valuation` + `get_realtime_quote.pe`,如果三者 diff > 5% emit warning
2. **decision 方向一致性**: 调用 `should_i_buy` + `should_i_sell(holding=0)` + `smart_stock_diagnosis` + `get_unified_decision`,4 工具方向必须 ≥3 同向才执行
3. **估值跨度**: 调用 `dcf_valuation` + `ddm_valuation` + `relative_valuation`,如果 max/min > 3× emit dispersion warning
4. **数据时效**: 关键数据(quote/north_fund/margin)`freshness_sec > 86400` 时拒绝使用
5. **样本量**: 任何统计指标 sample_size < 10 不作为决策依据

### 9.4 不要信任的字段

基于实测,以下字段在某些 case 下不可信:

- `quality_gate.freshness_sla.passed=true` — null 时 silent pass(S10-F08)
- `success=true` — 不代表数据有意义(empty list / count=0 / sector_correlation={})
- `fallback_used=false` — 即使 fallback 没用,数据也可能 stale
- `quality_flags=[]` 空 — 不代表数据完美,可能是 fallback chain 没触发到
- `degraded=false` — 跟 fallback_used=true 不一致(S12-F08 / S22-F09)
- `recommendation` 单工具 — 5 工具可能给 5 种方向(S17-F03)
- `intrinsic_price` 单估值器 — 5 工具跨度 8×(S17-F01)
- `change` 字段(get_north_fund_holding) — 当前是 absolute shares 而非 delta(S09-F12)
- `mkt_cap` 单位 — 跨工具 20 倍偏差(S06-F04)
- `industry_chain.matched=true` — build_stock_context 强制 fuzzy match(S02 / S06-F07 / S17-F05)
- `data_validation.passed=true` 当 evaluated_expectations=0 — silent vacuous pass(S06-F06)

**判定逻辑**(伪代码):

### E.3 P0-3 strategy_factory 多重检验校正

**根因**: 假设检验未做 BH/Holm 多重校正,143 candidates 92.7% block

**Step 1 — 引入 BH(Benjamini-Hochberg)校正**:
```python
import numpy as np

def benjamini_hochberg_correction(p_values, alpha=0.05):
    """
    BH FDR control:
    输入 N 个原始 p_value,返回 N 个 corrected p_value 和 reject mask
    """
    p_values = np.asarray(p_values)
    n = len(p_values)
    sorted_idx = np.argsort(p_values)
    sorted_p = p_values[sorted_idx]
    
    # BH critical value: i/n × alpha
    critical = np.arange(1, n+1) / n * alpha
    
    # find largest i such that sorted_p[i] <= critical[i]
    below = sorted_p <= critical
    if not below.any():
        rejected = np.zeros(n, dtype=bool)
    else:
        max_i = np.where(below)[0].max()
        rejected_sorted = np.arange(n) <= max_i
        rejected = np.zeros(n, dtype=bool)
        rejected[sorted_idx] = rejected_sorted
    
    # corrected p value (BH q-value)
    corrected = sorted_p * n / np.arange(1, n+1)
    corrected = np.minimum.accumulate(corrected[::-1])[::-1]
    p_adjusted = np.zeros(n)
    p_adjusted[sorted_idx] = np.minimum(corrected, 1.0)
    
    return p_adjusted, rejected
```
