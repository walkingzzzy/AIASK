## 1. 详细修复(按主题分类)

### 1.1 P1-3.1 / P1-3.2 / P1-3.3 — 跨工具 reconciliation 三件套

**根因**(诊断报告 §3.1 / §3.2 / §3.3):
- 同股同时刻 4 工具给 3 种 PE
- 5 估值器跨度 8×(11.6/18.2/68.6/91.2/95.9 元)
- 4-5 个 decision 工具同股给 3 种方向(hold/hold/sell/watch/sell)

**修复策略**:**新增 2 个 meta-tool + manager 内部数据对齐**

#### `valuation_consensus` 工具
新文件:`tools/valuation_consensus.py`(306 行)

签名:
```python
async def valuation_consensus(
    code, ...,
    growth_rate=0.05, discount_rate=0.10, ...,
    dispersion_warn_threshold=2.0,
    dispersion_high_threshold=3.0,
)
```

行为:
- 一次性调度 DCF / DDM / Relative-PE 三条估值路径
- 输出:`estimates / statistics{min/max/mean/median/stdev} / dispersion{ratio_max_over_min/severity}`
- 跨度 > 3× → `cross_method_dispersion_warning='high'`
- `consensus_recommendation.use_value = median`(降低极端值影响)
- 内置数学退化保护:DCF g>=r / DDM g>=r 强制 reject

#### `decision_consensus` 工具
新文件:`tools/decision_consensus.py`(280 行)

行为:
- 一次性查询 should_i_buy / should_i_sell / build_stock_context / smart_stock_diagnosis 4 工具
- 计算方向分布 + agreement_ratio
- agreement_ratio ≥ 0.6 → `consensus='agree'` + `actionable=dominant_direction`
- 0.4 ≤ ratio < 0.6 → `consensus='split'` + `actionable='hold'`(拿不准就 hold)
- ratio < 0.4 → `consensus='divergent'` + `actionable='no_action'`

#### manager 数据对齐(P1-3.4)
- `research_manager.get_reports/get_ratings`:tushare 失败时 fallback 到 `db.research_reports`
- `fundamental_analysis_manager.analyze`:metrics 缺 PE/PB 时自动 join `db.stocks`
- 中英文 rating mapping:'买入'/'增持'↔buy / '卖出'/'减持'↔sell / '持有'/'中性'↔hold

**根因**(诊断报告 §3.6):
- backtest assumption (slippage=0bps) vs execution assumption (slippage=5bps)
- governance_check_workflow 检测出 `online_offline:inconsistent` 但只是 emit warning
- promotion gate 不阻塞,导致 cohort 全 D 级仍能 proceed

- 任一命中 → 返回 `'online_offline_inconsistent'` blocker

#### P2-4.4.2 limit_up_down 校验补订单 price 维度
