### B1 — get_kline 索引路由 ✅

**测试1**: `get_kline(stock_code="000001")` → 仍按个股返回平安银行(向后兼容),但响应里**新增 ambiguity warning**:
```
fallback_reason: [
  "代码 000001 同时存在个股(平安银行/A股)和指数(上证/深证/创业板)语义，
   当前默认按个股查询。如需指数 K 线，请使用 'sh000001' / 'sz000001' 或调用 get_index_kline。"
]
```
AI 现在能看到代码冲突警告,可主动改用指数路径。

**测试2**: `get_kline(stock_code="sh000001")` → error=`"所有数据源均无法获取指数 000001 的K线数据"` — **明确路由到了 get_index_kline**(只是上游 akshare 拉指数 K 线失败,不再静默返个股)。

**测试3**: `get_index_quote("000001")` → ✅ 上证指数 4127.23,name="上证指数"(GBK 乱码也已修)。
