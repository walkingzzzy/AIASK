### 首次阅读建议

1. **必读**: [00-四工厂体系总览](00-四工厂体系总览.md)
2. **理解流程**: [01-策略工厂](01-策略工厂核心流程.md) → [03-孵化工厂](03-孵化工厂.md) → [04-SignalTracker](04-SignalTracker证据闭环.md)
