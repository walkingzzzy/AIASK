## 1. 功能设计

### 1.1 孵化阶段

| 阶段 | 目标 | 持续时间 | 退出条件 |
|------|------|----------|----------|
| Warmup | 策略预热，准备数据 | 1-3天 | 数据就绪 |
| Observe | 观察策略行为 | 7-14天 | 产生信号 |
| Paper | 模拟交易 | 30-90天 | 达到样本数 |
| Candidate | 晋级候选 | - | 通过Audit |
| Graduation | 准备上线 | - | 通过Hard Gate |

### 1.2 核心流程

```
submitted策略
    ↓
[1] Intake → 创建孵化账户
    ↓
[2] Warmup Phase
    ↓
[3] Observe Phase → 等待信号
    ↓
SignalTracker产生信号
    ↓
[4] Paper Orders → 模拟下单
    ↓
[5] Paper Trades → 模拟成交
    ↓
[6] Positions → 持仓管理
    ↓
[7] Stale Close → 超时平仓
    ↓
[8] Forward Returns → 前向收益
    ↓
[9] Execution Audit → 审计
    ↓
[10] Hard Gate → 晋级决策
    ├→ PASSED → Listed
    └→ PENDING → 继续积累样本
```

### 3.2 持仓退出率问题

**现象**: 99%的持仓处于open状态

**可能原因**:
1. Stale close policy未充分执行
2. 策略持有周期较长
3. 退出信号生成不足

**建议检查**:
```sql
-- 检查持仓aging分布
SELECT 
    JULIANDAY('now') - JULIANDAY(entry_time) as holding_days,
    COUNT(*) as count
FROM strategy_trade_positions
WHERE status = 'open'
GROUP BY CAST(JULIANDAY('now') - JULIANDAY(entry_time) AS INT)
ORDER BY holding_days DESC;
```

## 5. 执行审计

### 5.1 Audit Gate状态

**来源**: `packages/strategy-factory/src/strategy_factory/application/incubation/execution_audit_gate.py`

| Gate Status | 含义 | 是否通过Hard Gate |
|-------------|------|-------------------|
| `missing` | 无audit summary或无realized trade | ❌ 否 |
| `bootstrap_pending` | 有runtime evidence但realized_trade_count <= 0 | ❌ 否 |
| `insufficient_samples` | realized trades > 0但低于bootstrap floor | ❌ 否 |
| `failed_metrics` | 样本达到bootstrap floor但指标失败 | ❌ 否 |
| `bootstrap_ready` | 指标通过且达到bootstrap floor但低于production floor | ❌ 否 |
| `passed` | 指标通过且 realized_trade_count >= 20 | ✅ 是 |

### 5.2 Hard Gate标准

**Production Trade Floor**: 20个真实paper closed round-trip

**拒绝的输入**:
- Bootstrap数据 (realized_trade_count < 20)
- Backtest数据
- 无成交的信号

**实际数据** (2026-06-21):
- Audit快照: 20,392
- Hard Gate通过: 1
- 通过率: 0.005% ✅ (符合严格标准)

### 8.2 SQL查询示例

```sql
-- 查询孵化账户分布
SELECT stage, COUNT(*) as count
FROM strategy_incubation_accounts
WHERE status = 'active'
GROUP BY stage;

-- 查询持仓aging
SELECT 
    CASE 
        WHEN JULIANDAY('now') - JULIANDAY(entry_time) < 7 THEN '<1周'
        WHEN JULIANDAY('now') - JULIANDAY(entry_time) < 30 THEN '1-4周'
        WHEN JULIANDAY('now') - JULIANDAY(entry_time) < 90 THEN '1-3月'
        ELSE '>3月'
    END as holding_period,
    COUNT(*) as count
FROM strategy_trade_positions
WHERE status = 'open'
GROUP BY holding_period;

-- 查询Hard Gate通过情况
SELECT 
    verdict_status,
    COUNT(*) as count,
    ROUND(100.0 * COUNT(*) / SUM(COUNT(*)) OVER (), 2) as percentage
FROM strategy_execution_audit_snapshots
GROUP BY verdict_status
ORDER BY count DESC;
```
