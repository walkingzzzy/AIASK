## 1. 数据库配置

### 1.1 SQLite路径

**环境变量**: `AKSHARE_MCP_SQLITE_PATH`

**默认值**: `data/db/akshare_mcp.sqlite3`

**配置方法**:
```bash
# Linux/Mac
export AKSHARE_MCP_SQLITE_PATH=/path/to/database.sqlite3

# Windows
set AKSHARE_MCP_SQLITE_PATH=C:\path\to\database.sqlite3
```

**验证配置**:
```bash
python -c "from aiask_quant_core.config import get_settings; print(get_settings().sqlite_path)"
```

### 1.2 数据库连接池

**环境变量**: `DB_POOL_SIZE`

**默认值**: `10`

**配置示例**:
```bash
export DB_POOL_SIZE=20
```

## 2. 四工厂配置

### 2.1 运行间隔

**环境变量**: `FACTORY_RUN_INTERVAL`

**默认值**: `3600` (秒)

### 2.2 批量大小

**环境变量**: `FACTORY_BATCH_SIZE`

**默认值**: `100`

## 3. SignalTracker配置

### 3.1 运行频率

**环境变量**: `SIGNAL_TRACKER_INTERVAL`

**默认值**: `3600` (秒)

**建议值**: `1800-3600` (30分钟-1小时)

### 3.2 Phase Timeout

**环境变量**: `SIGNAL_TRACKER_PHASE_TIMEOUT`

**默认值**: `1800` (秒)

## 4. Hard Gate配置

### 4.1 Production Trade Floor

**环境变量**: `PRODUCTION_TRADE_FLOOR`

**默认值**: `20`

**禁止**: 降低此值！

### 4.2 Bootstrap Floor

**环境变量**: `BOOTSTRAP_TRADE_FLOOR`

**默认值**: `1`

## 5. 日志配置

### 5.1 日志级别

**环境变量**: `LOG_LEVEL`

**默认值**: `INFO`

**可选值**: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`

### 5.2 日志路径

**环境变量**: `LOG_DIR`

**默认值**: `logs/`

## 6. Python路径

**环境变量**: `PYTHONPATH`

**必须包含**:
```bash
# Linux/Mac
export PYTHONPATH=/path/to/aiask/packages/strategy-factory/src:/path/to/aiask/packages/aiask-quant-core/src:$PYTHONPATH

# Windows
set PYTHONPATH=C:\path\to\aiask\packages\strategy-factory\src;C:\path\to\aiask\packages\aiask-quant-core\src;%PYTHONPATH%
```

## 7. 完整配置示例

```bash
# .env 文件
AKSHARE_MCP_SQLITE_PATH=data/db/akshare_mcp.sqlite3
DB_POOL_SIZE=10
FACTORY_RUN_INTERVAL=3600
FACTORY_BATCH_SIZE=100
SIGNAL_TRACKER_INTERVAL=3600
SIGNAL_TRACKER_PHASE_TIMEOUT=1800
PRODUCTION_TRADE_FLOOR=20
BOOTSTRAP_TRADE_FLOOR=1
LOG_LEVEL=INFO
LOG_DIR=logs/
```
