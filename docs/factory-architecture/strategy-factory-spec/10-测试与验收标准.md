### 2.2 SQL验证测试

```sql
-- TC-INT-002: 信号→订单转换率
SELECT 
    COUNT(DISTINCT s.strategy_id) as with_signals,
    COUNT(DISTINCT o.strategy_id) as with_orders,
    ROUND(100.0 * COUNT(DISTINCT o.strategy_id) / COUNT(DISTINCT s.strategy_id), 2) as rate
FROM strategy_signals s
LEFT JOIN paper_orders o ON s.strategy_id = o.strategy_id;
-- 预期: rate > 95

-- TC-INT-003: 订单→成交转换率
SELECT 
    COUNT(*) as total_orders,
    COUNT(t.id) as filled_orders,
    ROUND(100.0 * COUNT(t.id) / COUNT(*), 2) as rate
FROM paper_orders o
LEFT JOIN paper_trades t ON o.id = t.order_id;
-- 预期: rate > 95
```

## 3. E2E测试

### 3.1 完整生命周期测试

**测试场景**: 从策略生成到Hard Gate

**步骤**:
1. 生成1个策略候选
2. 通过Gate评估
3. 进入孵化
4. 产生信号
5. 生成订单
6. 订单成交
7. 形成持仓
8. 计算前向收益
9. 执行审计
10. 评估Gate状态

**预期结果**:
- 策略状态正确转换
- 证据表有对应记录
- Audit快照生成
- Gate status为bootstrap_pending或insufficient_samples（样本债）
