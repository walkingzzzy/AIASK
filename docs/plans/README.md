# 开发方案导读

`docs/plans/` 只保留两类材料：

1. 当前仍会被开发/评审直接引用的协议与实施文档
2. 因外部引用关系需要继续保留原路径的历史材料

其余明确属于历史盘点、阶段性审计、研究蓝图的内容，已经收进 [`archive/`](./archive/README.md)。

## 阅读决策

1. 你要改接口或数据结构：先看协议文档。
2. 你要做策略工厂相关开发：先看根目录 `策略工厂/` 文档集和 `策略工厂重构方案.md`。
3. 你要了解某个历史判断从哪里来：再进入保留原路径的历史材料。
4. 你要做当前 Web / BFF 页面或接口开发：若 `docs/` 中没有现行专题文档，直接以 `apps/web/app` 与 `apps/bff/src` 源码为准。
5. 你只是想补背景或看过去怎么规划：最后再去 `archive/`。
