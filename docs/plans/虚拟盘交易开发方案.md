### 1.2 MCP `paper_trading_manager` 已知缺陷

1. **佣金始终为 0**：`paper_trades.commission` 字段 DEFAULT 0，manager 从未计算佣金
2. **无 T+1 校验**：卖出时仅检查 `position.quantity >= shares`，不区分今日买入
3. **无整手校验**：买入不要求 100 股整数倍
4. **无涨跌停校验**：不校验委托价格是否在涨跌停范围内
5. **stock_name 解析不稳定**：依赖行情接口返回名称，失败时回退为代码本身

### 1.3 关键约束

- BFF 层需要先恢复基础设施（`app.module.ts`、`mcp-gateway`、`auth`、`rbac` 等），或从 git HEAD 恢复，才能新增 paper-trading 模块
- 前端不存在 `useAutoRefresh` hook，需自行实现或用 `setInterval` 替代
- 前端不存在 `StockLink` 组件，持仓表中股票代码直接显示文本即可
- `DataTable` 的 prop 是 `rows`（非 `data`），`KpiCard` 的 prop 是 `title`（非 `label`）

## 二、A 股交易规则

### 2.1 T+1 交割

当日买入次日方可卖出。通过 `paper_trades` 表聚合计算可卖数量：

```sql
SELECT COALESCE(SUM(
  CASE WHEN trade_type = 'buy' AND DATE(trade_time) < CURRENT_DATE THEN quantity
       WHEN trade_type = 'sell' THEN -quantity
       ELSE 0 END
), 0) as sellable_quantity
FROM paper_trades
WHERE account_id = $1 AND stock_code = $2;
```

无需修改表结构。

### 2.2 涨跌停

| 板块 | 代码特征 | 限制 |
|------|---------|------|
| 主板 | 600/601/603/000/001/002 | ±10% |
| 创业板 | 300xxx | ±20% |
| 科创板 | 688xxx | ±20% |
| ST | 名称含 ST | ±5% |
| 北交所 | 8xxxxx / 4xxxxx | ±30% |

### 2.3 整手交易

买入必须 100 股整数倍，卖出允许零股。

### 2.4 佣金

```
买入：佣金 max(金额×0.025%, 5元) + 过户费 金额×0.001%
卖出：佣金 max(金额×0.025%, 5元) + 印花税 金额×0.05% + 过户费 金额×0.001%
```

### 4.4 Controller（完整代码，对齐 portfolio 风格）

```typescript
import { Body, Controller, Get, Post, Query, Req } from '@nestjs/common';
import { IsIn, IsInt, IsNumber, IsOptional, IsString, Matches, Min } from 'class-validator';
import { Type } from 'class-transformer';
import { PaperTradingService } from './paper-trading.service';

class CreateAccountDto {
  @IsOptional() @IsString()
  name?: string;

  @IsOptional() @Type(() => Number) @IsNumber()
  initialCapital?: number;
}

class PlaceOrderDto {
  @IsOptional() @IsString()
  accountId?: string;

  @IsString() @Matches(/^\d{6}$/, { message: 'code 必须为 6 位数字' })
  code!: string;

  @IsIn(['buy', 'sell'])
  direction!: 'buy' | 'sell';

  @Type(() => Number) @IsInt() @Min(1)
  quantity!: number;

  @IsOptional() @Type(() => Number) @IsNumber()
  price?: number;
}

function traceId(req: any): string {
  return String(req.traceId || req.headers?.['x-trace-id'] || req.headers?.['x-request-id'] || 'UNKNOWN');
}

@Controller('paper-trading')
export class PaperTradingController {
  constructor(private readonly svc: PaperTradingService) {}

  @Post('account')
  async createAccount(@Body() dto: CreateAccountDto, @Req() req: any) {
    return { success: true, data: await this.svc.createAccount(dto), traceId: traceId(req) };
  }

  @Post('order')
  async placeOrder(@Body() dto: PlaceOrderDto, @Req() req: any) {
    return { success: true, data: await this.svc.placeOrder(dto), traceId: traceId(req) };
  }

  @Get('positions')
  async positions(@Query('accountId') accountId: string, @Req() req: any) {
    return { success: true, data: await this.svc.getPositions(accountId), traceId: traceId(req) };
  }

  @Get('orders')
  async orders(@Query('accountId') accountId: string, @Req() req: any) {
    return { success: true, data: await this.svc.getOrders(accountId), traceId: traceId(req) };
  }

  @Get('summary')
  async summary(@Query('accountId') accountId: string, @Req() req: any) {
    return { success: true, data: await this.svc.getSummary(accountId), traceId: traceId(req) };
  }

  @Get('quote')
  async quote(@Query('code') code: string, @Req() req: any) {
    return { success: true, data: await this.svc.getQuote(code), traceId: traceId(req) };
  }
}
```

### 4.5 Service（完整代码）

```typescript
import { BadGatewayException, Injectable } from '@nestjs/common';
import { McpGatewayService } from '../mcp-gateway/mcp-gateway.service';

@Injectable()
export class PaperTradingService {
  constructor(private readonly mcpGateway: McpGatewayService) {}

  async createAccount(dto: { name?: string; initialCapital?: number }) {
    return this.callManager('create_account', {
      name: dto.name?.trim() || '默认模拟账户',
      initial_capital: dto.initialCapital ?? 100000,
    });
  }

  async placeOrder(dto: { accountId?: string; code: string; direction: string; quantity: number; price?: number }) {
    const kw: Record<string, unknown> = { code: dto.code, direction: dto.direction, quantity: dto.quantity };
    if (dto.accountId) kw.account_id = dto.accountId;
    if (dto.price != null) kw.price = dto.price;
    return this.callManager('place_order', kw);
  }

  async getPositions(accountId?: string) {
    return this.callManager('positions', accountId ? { account_id: accountId } : {});
  }

  async getOrders(accountId?: string) {
    return this.callManager('orders', accountId ? { account_id: accountId } : {});
  }

  async getSummary(accountId?: string) {
    return this.callManager('summary', accountId ? { account_id: accountId } : {});
  }

  async getQuote(code: string) {
    try {
      const result = await this.mcpGateway.callTool('get_realtime_quote', { code });
      return { sourceTool: 'get_realtime_quote', result };
    } catch (e) {
      throw new BadGatewayException({
        success: false, message: 'MCP get_realtime_quote 调用失败',
        detail: e instanceof Error ? e.message : String(e),
      });
    }
  }

  private async callManager(action: string, kwargs: Record<string, unknown> = {}) {
    try {
      const result = await this.mcpGateway.callTool('paper_trading_manager', {
        action, kwargs: JSON.stringify(kwargs),
      });
      return { sourceTool: 'paper_trading_manager', result };
    } catch (e) {
      throw new BadGatewayException({
        success: false, message: `MCP paper_trading_manager.${action} 调用失败`,
        detail: e instanceof Error ? e.message : String(e),
      });
    }
  }
}
```

### 5.4 page.tsx 完整设计

参照 `strategy/page.tsx` 的实际模式：

```tsx
'use client';

import { useCallback, useEffect, useMemo, useRef, useState } from 'react';
import {
  PageContainer, SectionCard, StockCodeInput, DataTable,
  KpiCard, KpiGrid, TabBar, Badge, ConfirmDialog,
} from '@/components/ui';
import { useApiMutation } from '@/hooks/use-api-mutation';
import { useStockCode } from '@/hooks/use-stock-code';
import { ErrorState, LoadingState } from '@/components/status-state';
import { extractArray, extractObject, fmtNum, fmtAmount, fmtPct } from '@/lib/data-utils';
import { exportCSV } from '@/lib/export';
import { useToast } from '@/components/ui/toast';

// ── Tab 定义 ──
const TABS = [
  { key: 'overview', label: '账户总览' },
  { key: 'trade', label: '交易下单' },
  { key: 'positions', label: '我的持仓' },
  { key: 'history', label: '交易记录' },
] as const;
type TabKey = (typeof TABS)[number]['key'];

// ── 费用预估（前端展示用） ──
function estimateFees(amount: number, direction: 'buy' | 'sell'): number {
  const commission = Math.max(amount * 0.00025, 5);
  const stampTax = direction === 'sell' ? amount * 0.0005 : 0;
  const transferFee = amount * 0.00001;
  return commission + stampTax + transferFee;
}

export default function PaperTradingPage() {
  const [tab, setTab] = useState<TabKey>('overview');
  const { code, setCode, codeError, validate, trimmedCode } = useStockCode('');
  const [direction, setDirection] = useState<'buy' | 'sell'>('buy');
  const [quantity, setQuantity] = useState(100);
  const [confirmOpen, setConfirmOpen] = useState(false);
  const [formError, setFormError] = useState<string | null>(null);
  const toast = useToast();

  // ── API mutations ──
  const summaryApi = useApiMutation<unknown>();
  const positionsApi = useApiMutation<unknown>();
  const ordersApi = useApiMutation<unknown>();
  const quoteApi = useApiMutation<unknown>();
  const orderApi = useApiMutation<unknown>();
  const accountApi = useApiMutation<unknown>();

  // ── 数据加载 ──
  const refreshAll = useCallback(() => {
    summaryApi.trigger('/paper-trading/summary');
    positionsApi.trigger('/paper-trading/positions');
    ordersApi.trigger('/paper-trading/orders');
  }, []);

  useEffect(() => { refreshAll(); }, [refreshAll]);

  // ── 轮询（交易时段每 15 秒） ──
  useEffect(() => {
    const now = new Date();
    const h = now.getHours(), m = now.getMinutes();
    const mins = h * 60 + m;
    const trading = (mins >= 570 && mins <= 690) || (mins >= 780 && mins <= 900); // 9:30-11:30, 13:00-15:00
    if (!trading) return;
    const id = setInterval(refreshAll, 15_000);
    return () => clearInterval(id);
  }, [refreshAll]);

  // ── 下单逻辑 ──
  function handleOrder() {
    setFormError(null);
    if (!validate()) return;
    if (direction === 'buy' && quantity % 100 !== 0) {
      setFormError('买入数量必须为 100 的整数倍');
      return;
    }
    if (quantity <= 0) { setFormError('数量必须大于 0'); return; }
    setConfirmOpen(true);
  }

  async function submitOrder() {
    setConfirmOpen(false);
    try {
      await orderApi.triggerAsync('/paper-trading/order', { method: 'POST' }, {
        code: trimmedCode, direction, quantity,
      });
      toast.success(`${direction === 'buy' ? '买入' : '卖出'}成功`);
      refreshAll();
    } catch { /* useApiMutation 已捕获 */ }
  }

  function fetchQuote() {
    if (!validate()) return;
    quoteApi.trigger(`/paper-trading/quote?code=${trimmedCode}`);
  }

  // ── 数据提取 ──
  const summary = useMemo(() => {
    if (!summaryApi.data) return null;
    return extractObject(summaryApi.data) as Record<string, unknown>;
  }, [summaryApi.data]);

  const positions = useMemo(
    () => extractArray(positionsApi.data, 'positions', 'data', 'list'),
    [positionsApi.data],
  );

  const trades = useMemo(
    () => extractArray(ordersApi.data, 'trades', 'orders', 'data', 'list'),
    [ordersApi.data],
  );

  const quote = useMemo(() => {
    if (!quoteApi.data) return null;
    return extractObject(quoteApi.data) as Record<string, unknown>;
  }, [quoteApi.data]);

  const loading = summaryApi.isPending || positionsApi.isPending || ordersApi.isPending
    || quoteApi.isPending || orderApi.isPending;
  const error = formError || summaryApi.error || positionsApi.error || ordersApi.error
    || quoteApi.error || orderApi.error;

  // ── 快捷卖出 ──
  function quickSell(row: Record<string, unknown>) {
    setCode(String(row.stock_code ?? ''));
    setDirection('sell');
    setQuantity(Number(row.quantity) || 100);
    setTab('trade');
  }

  const estAmount = quantity * (Number(quote?.price ?? quote?.current_price ?? 0) || 0);

  return (
    <PageContainer>
      <h1>模拟交易</h1>
      <TabBar tabs={TABS} active={tab} onChange={setTab} />

      {loading ? <LoadingState text="处理中..." /> : null}
      {error ? <ErrorState text={error} /> : null}

      {/* ── 账户总览 Tab ── */}
      {tab === 'overview' && (
        <SectionCard tabAttached>
          <KpiGrid cols={4}>
            <KpiCard title="总资产" value={summary ? fmtAmount(summary.total_value ?? summary.totalValue) : null} />
            <KpiCard title="可用资金" value={summary ? fmtAmount(summary.current_capital ?? summary.currentCapital) : null} />
            <KpiCard title="初始资金" value={summary ? fmtAmount(summary.initial_capital ?? summary.initialCapital) : null} />
            <KpiCard title="持仓数" value={positions.length || null} />
          </KpiGrid>
          {positions.length > 0 && (
            <div className="mt-3">
              <h3 className="mt-0 text-sm font-semibold">持仓概览</h3>
              <DataTable rows={positions} pageSize={5} />
            </div>
          )}
        </SectionCard>
      )}

      {/* ── 交易下单 Tab ── */}
      {tab === 'trade' && (
        <SectionCard tabAttached>
          {/* 买卖切换 */}
          <div className="flex gap-2 mb-3">
            <button
              onClick={() => setDirection('buy')}
              className={`px-4 py-2 rounded text-sm font-semibold cursor-pointer ${
                direction === 'buy' ? 'bg-[#ef4444] text-white' : 'border border-border'
              }`}
            >买入</button>
            <button
              onClick={() => setDirection('sell')}
              className={`px-4 py-2 rounded text-sm font-semibold cursor-pointer ${
                direction === 'sell' ? 'bg-[#10b981] text-white' : 'border border-border'
              }`}
            >卖出</button>
          </div>

          <div className="flex gap-4 flex-wrap">
            {/* 左：行情 */}
            <div className="flex-1 min-w-[200px]">
              <div className="flex gap-2 items-end mb-2">
                <StockCodeInput value={code} onChange={setCode} error={codeError} />
                <button onClick={fetchQuote} className="px-3 py-1 border border-border rounded text-sm cursor-pointer">
                  查行情
                </button>
              </div>
              {quote && (
                <div className="text-sm space-y-1 mt-2">
                  <div>名称：{String(quote.name ?? quote.stock_name ?? '-')}</div>
                  <div>现价：{fmtNum(quote.price ?? quote.current_price, 2)}</div>
                  <div>涨跌幅：<span className={Number(quote.change_pct ?? 0) >= 0 ? 'text-danger' : 'text-success'}>
                    {fmtPct(quote.change_pct ?? quote.pct_change)}
                  </span></div>
                </div>
              )}
            </div>

            {/* 右：下单表单 */}
            <div className="flex-1 min-w-[200px]">
              <div className="mb-2">
                <label className="text-xs text-text-secondary">数量（股）</label>
                <input type="number" value={quantity} onChange={(e) => setQuantity(Number(e.target.value) || 0)}
                  min={1} step={100} className="w-full px-2 py-1 border border-border rounded text-sm mt-1" />
              </div>
              <div className="flex gap-1 mb-2 flex-wrap">
                {[100, 500, 1000].map((n) => (
                  <button key={n} onClick={() => setQuantity(n)}
                    className="px-2 py-0.5 border border-border rounded text-xs cursor-pointer">{n}股</button>
                ))}
              </div>
              {estAmount > 0 && (
                <div className="text-xs text-text-secondary mb-2">
                  预估金额：{fmtAmount(estAmount)}　手续费：≈{fmtNum(estimateFees(estAmount, direction), 2)}元
                </div>
              )}
              <button onClick={handleOrder}
                className={`w-full py-2 rounded text-white font-semibold cursor-pointer ${
                  direction === 'buy' ? 'bg-[#ef4444]' : 'bg-[#10b981]'
                }`}>
                {orderApi.isPending ? '提交中...' : direction === 'buy' ? '确认买入' : '确认卖出'}
              </button>
            </div>
          </div>
        </SectionCard>
      )}

      {/* ── 持仓 Tab ── */}
      {tab === 'positions' && (
        <SectionCard tabAttached>
          <div className="flex justify-between items-center mb-2">
            <h3 className="mt-0 text-sm font-semibold">当前持仓</h3>
            <button onClick={() => positionsApi.trigger('/paper-trading/positions')}
              className="text-xs px-2 py-1 border border-border rounded cursor-pointer">刷新</button>
          </div>
          <DataTable
            rows={positions}
            columns={[
              { key: 'stock_code', label: '代码' },
              { key: 'stock_name', label: '名称' },
              { key: 'quantity', label: '持仓' },
              { key: 'cost_price', label: '成本', render: (v: unknown) => fmtNum(v, 2) },
              { key: 'current_price', label: '现价', render: (v: unknown) => fmtNum(v, 2) },
              { key: 'market_value', label: '市值', render: (v: unknown) => fmtAmount(v) },
              { key: 'profit_rate', label: '盈亏%', render: (v: unknown) => {
                const n = Number(v);
                return <span className={n >= 0 ? 'text-danger' : 'text-success'}>{fmtPct(n)}</span>;
              }},
              { key: '_action', label: '操作', render: (_: unknown, row: Record<string, unknown>) => (
                <button onClick={() => quickSell(row)}
                  className="text-xs px-2 py-0.5 border border-border rounded cursor-pointer">卖出</button>
              )},
            ]}
            onExport={() => exportCSV(positions, 'paper-positions')}
          />
        </SectionCard>
      )}

      {/* ── 交易记录 Tab ── */}
      {tab === 'history' && (
        <SectionCard tabAttached>
          <DataTable
            rows={trades}
            columns={[
              { key: 'trade_time', label: '时间' },
              { key: 'stock_code', label: '代码' },
              { key: 'stock_name', label: '名称' },
              { key: 'trade_type', label: '方向', render: (v: unknown) => (
                <Badge variant={v === 'buy' ? 'danger' : 'success'}>
                  {v === 'buy' ? '买入' : '卖出'}
                </Badge>
              )},
              { key: 'price', label: '成交价', render: (v: unknown) => fmtNum(v, 2) },
              { key: 'quantity', label: '数量' },
              { key: 'amount', label: '金额', render: (v: unknown) => fmtAmount(v) },
            ]}
            onExport={() => exportCSV(trades, 'paper-trades')}
          />
        </SectionCard>
      )}

      <ConfirmDialog
        open={confirmOpen}
        title={`确认${direction === 'buy' ? '买入' : '卖出'}`}
        message={`${direction === 'buy' ? '买入' : '卖出'} ${trimmedCode}，数量 ${quantity} 股`}
        onConfirm={submitOrder}
        onCancel={() => setConfirmOpen(false)}
        danger={direction === 'sell'}
      />
    </PageContainer>
  );
}
```

def _calc_commission(amount: float, direction: str) -> float:

## 七、实时行情方案

### 方案：setInterval 轮询

项目中 `useAutoRefresh` hook 不存在，使用原生 `setInterval`：

```tsx
useEffect(() => {
  const now = new Date();
  const mins = now.getHours() * 60 + now.getMinutes();
  const trading = (mins >= 570 && mins <= 690) || (mins >= 780 && mins <= 900);
  if (!trading) return;
  const id = setInterval(refreshAll, 15_000);
  return () => clearInterval(id);
}, [refreshAll]);
```

- 交易时段（9:30-11:30, 13:00-15:00）：每 15 秒刷新
- 非交易时段：不自动刷新，用户手动点击刷新按钮
- 行情数据来自 akshare，可能有延迟，UI 需提示「行情数据可能延迟 15-30 分钟」

## 九、技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 页面结构 | 单文件 page.tsx + TabBar | 与 strategy/page.tsx 风格一致，项目中无拆分子组件的先例 |
| 行情刷新 | setInterval 15s | `useAutoRefresh` 不存在，原生实现简单可靠 |
| 状态管理 | 页面内 useState | accountId 由 MCP 自动创建，无需跨页面持久化 |
| 订单类型 | 仅市价单 | MCP 已支持自动获取行情价格，限价单复杂度高延后 |
| BFF 恢复 | git checkout HEAD | 最快路径，一条命令恢复全部 |
| DTO 风格 | 内联在 controller | 与 portfolio.controller.ts 一致 |
| 子组件拆分 | 不拆分 | 项目中 strategy 等页面均为单文件，保持一致 |
