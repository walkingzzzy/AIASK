# AIASK 个人功能开发方案


> 校准说明：本文属于历史功能开发方案，用于描述当时对“个人功能”模块的能力盘点、缺口分析和实施路径。
>
> 文中“已实现”“完整”“可用”等状态标签带有编制时点属性，当前是否仍成立需要结合最新代码、接口接线、测试结果与运行日志重新核实；若与当前实现冲突，应以后者为准。

## 一、现状分析

### 已实现

| 模块 | 功能 | 状态 |
|------|------|------|
| 认证 | 注册/登录/登出/Token 刷新 | ✅ 完整 |
| RBAC | 全局 AuthGuard + @Roles 装饰器 | ✅ 完整 |
| 设置 | LLM 配置（AES-256-GCM 加密存储） | ✅ 完整 |
| 设置 | 主题切换（light/dark/system） | ✅ 完整 |
| 设置 | 风险偏好下拉选择 | ⚠️ 前端有 UI，后端不持久化 |
| 模拟盘 | 开户/下单/持仓/交易记录/行情 | ✅ 完整 |
| 组合 | 创建/持仓/优化/风险/压力测试 | ✅ 完整 |
| 预警 | 创建/列表/删除 | ⚠️ 无推送机制 |
| AI 对话 | 多会话/流式/工具调用/用户上下文注入 | ✅ 完整 |
| 审计 | 全局请求日志（管理员可查） | ✅ 完整 |

### 核心缺失

| 缺失项 | 影响 |
|--------|------|
| 修改密码 | 用户注册后永远无法改密码 |
| Profile 持久化 | 风险偏好保存后刷新即丢失 |
| 自选股管理 | MCP 后端有 watchlist_manager，前端零 UI |
| 个人 Dashboard | 首页直接跳 /chat，无行情/持仓/预警概览 |
| 通知/推送 | 预警触发后用户无感知 |
| 收益统计 | 模拟盘无历史收益曲线和绩效分析 |
| 登录历史 | 用户看不到自己的安全日志 |
| 头像/昵称 | 仅显示 username 文本 |
| 新手引导 | 新用户不知道如何开始 |
| 数据导出 | 无统一的个人数据打包下载 |

## 四、技术要点

### 复用现有基础设施

| 基础设施 | 用途 |
|----------|------|
| `McpGatewayService.callTool()` | 自选股管理、预警检查、数据导出 |
| `CommonCacheService` | 自选股行情缓存（TTL 30s）、通知计数缓存 |
| `PreferencesService` | profile 持久化（riskLevel, nickname, avatarUrl） |
| `AuditStore` | 用户安全日志查询 |
| `useApiMutation<T>()` | 前端所有数据请求 |
| `authedFetch()` | 自动 token 刷新 + 401 处理 |
| `extractArray() / extractObject()` | MCP 响应解包 |
| `exportCSV()` | 表格数据导出 |
| `PageContainer + TabBar + SectionCard` | 页面布局 |
| `KpiCard + KpiGrid + DataTable` | 数据展示 |

### 不引入新依赖

- 通知轮询用 `setInterval`（前端）+ `@nestjs/schedule`（后端，已有）
- 新手引导用纯 CSS + React portal，不引入 react-joyride 等
- 头像用 DiceBear URL 或用户输入 URL，不引入文件上传
- 数据导出用 JSON 下载，不引入 PDF 生成库

### 数据流示意

```
用户操作                    前端                      BFF                    MCP
────────                  ──────                    ────                   ────
添加自选股 ──→ POST /watchlist/add ──→ watchlist_manager(add) ──→ akshare-mcp
查看自选行情 ──→ GET /watchlist/list ──→ watchlist_manager(list) ──→ akshare-mcp
              POST /market/batch-quotes ──→ get_batch_quotes ──→ akshare-mcp

预警触发 ←── 通知铃铛轮询 ←── GET /notification/unread-count
                              ↑
                    @Cron 每分钟 ──→ check_all_alerts ──→ akshare-mcp
                              ↓
                    notificationStore.append()

Dashboard ──→ 并行 5 个 GET ──→ 各 Service ──→ 各 MCP 工具
```
