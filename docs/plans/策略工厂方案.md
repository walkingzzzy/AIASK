### 1.1 数据能力（今天就能拿到的数据）

| 数据 | 来源 | 获取方式 | 频率 |

| 上证指数K线 | DB `kline_1d` code=sh000001 | `db.get_klines('sh000001')` | 日 |
| 北向资金 | Tushare→HKEX→AKShare | `get_north_fund()` | 日 |
| 板块资金流 | AKShare→东方财富API | `get_sector_fund_flow()` | 日 |

| 实时行情 | TDX→AKShare | `get_realtime_quote()` | 实时 |

### 1.2 计算能力（今天就能算的指标）

**38个可用因子（仅需K线）：**
- 动量类：`momentum`, `mom_1d/5d/10d/60d`, `roc_10/20`
- 趋势类：`trend`, `macd_signal/histogram`
- 反转类：`reversal`, `rsi_14/6`, `willr_14`, `cci_20`, `stoch_k/d`
- 波动类：`volatility`, `vol_5d/10d/60d`, `atr_14/20`, `bollinger_width`, `downside_vol`
- 量价类：`volume_ratio`, `obv_slope`, `vwap_deviation`, `turnover_5d/20d`, `mfi_14`

**10个基本面因子（需财务数据）：**
- `value`(PE/PB/PS合成), `quality`(ROE+负债率+利润增速), `growth`(营收+利润增速)
- `size`, `pe_ttm`, `pb_mrq`, `roe_ttm`, `gross_margin`, `debt_to_equity`, `dividend_yield`

**5个替代因子 — 全部是空壳（return None）：**
- `sentiment_score`, `capital_flow`, `north_flow`, `institutional_flow`, `event_intensity`

**恐贪指数（4分量）：**
- 动量分量：5日指数涨跌幅 × 4 + 50
- 波动分量：75 - 20日波动率 × 8（高波动=低分=恐惧）
- 成交量分量：5日/15日量比 × 25 + 50
- 广度分量：**缺失**（`get_limit_up_stats()` 未实现，永远返回50）

**情绪系统（3分量）：**
- 价格动量40%：20日涨跌幅 + 量比
- 新闻情绪30%：中文关键词匹配（但需要外部传入新闻标题）
- 资金流30%：北向资金 + 融资变化（但需要外部传入数值）

### 1.3 回测能力

- `BacktestEngine.run_backtest(code, klines, strategy, params)` — 输入K线列表，输出Sharpe/收益/回撤/胜率
- 支持3种滑点模型、涨跌停过滤、next-bar执行
- 支持 StrategyRegistry 回退 — 任何注册的 IStrategy 子类都能回测
- 4种内置策略：ma_cross, momentum, rsi, buy_and_hold

### 1.4 已有但坏掉的

| 问题 | 位置 | 影响 |
|------|------|------|
| 质检管线 ImportError | `strategy_manager.py` 导入不存在的函数 | 所有策略提交被拒 |
| IC用回溯收益 | `quant_manager.py` batch_compute_factors | IC值无意义 |

```python
for i in range(len(factor_vals) - period):
```

### 2.3 实现 get_limit_up_stats()（P0）

恐贪指数的广度分量依赖它，不实现则恐贪指数永远缺一条腿。

```python
# 从 kline_1d 表统计涨跌停
async def get_limit_up_stats(self, date=None):
    sql = """
        SELECT
            COUNT(*) FILTER (WHERE close >= prev_close * 1.098) as limit_up,
            COUNT(*) FILTER (WHERE close <= prev_close * 0.902) as limit_down,
            COUNT(*) FILTER (WHERE close > prev_close) as advance,
            COUNT(*) FILTER (WHERE close < prev_close) as decline
        FROM (
            SELECT close, LAG(close) OVER (PARTITION BY code ORDER BY time) as prev_close
            FROM kline_1d WHERE time::date = $1
        ) t WHERE prev_close IS NOT NULL
    """
    return await self.fetchrow(sql, date or datetime.now().date())
```

## 三、策略工厂的核心逻辑

### 3.1 思路

不搞理论框架，直接回答一个问题：**系统今天能算出什么数据，这些数据能驱动生成什么策略？**

```
每天18:00后，系统拥有：
├── 160只股票的最新K线 → 38个技术因子值
├── 160只股票的财务数据 → 10个基本面因子值
├── 各因子的IC值（修复后） → 知道哪个因子最近"灵"
├── 上证指数K线 → 恐贪指数4分量
├── 北向资金净买入额 → 外资态度
├── 板块资金流向 → 哪些板块在吸金
├── 融资余额变化 → 杠杆资金态度
└── 涨跌停统计（修复后） → 市场情绪温度

问题：这些数据怎么变成策略商品？
```

### 3.2 数据状态 → 策略生成的映射关系

这是整个方案的核心。不是"市场是牛市所以生成动量策略"这种粗糙映射，而是**每个数据信号直接对应一种策略参数选择**：

```
数据信号                          → 策略生成动作
─────────────────────────────────────────────────────────────
恐贪指数 < 30（恐惧）             → 生成RSI反转策略（oversold=25, 更激进抄底）
                                    生成价值因子策略（top_pct=0.1, 精选深度价值）

恐贪指数 > 70（贪婪）             → 生成动量策略（lookback=5, 短周期追涨）
                                    生成RSI策略（overbought=65, 更敏感逃顶）

波动率分量 < 35（高波动）          → 生成均线策略（long_period=40/60, 长周期过滤噪声）
                                    生成动量策略（threshold=0.05, 高阈值过滤假突破）

波动率分量 > 65（低波动）          → 生成均线策略（short=3/5, long=15/20, 短周期捕捉微弱趋势）
                                    生成动量策略（threshold=0.01, 低阈值）

momentum因子IC > 0.03（动量有效） → 生成动量策略（多个lookback变体）
                                    多因子策略中momentum权重上调

value因子IC > 0.03（价值有效）    → 生成价值因子策略（多个top_pct变体）
                                    多因子策略中value权重上调

reversal因子IC > 0.03（反转有效） → 生成RSI策略（多个period/阈值变体）

北向资金连续3日净流入 > 50亿      → 生成成长因子策略（外资偏好成长股）
北向资金连续3日净流出 > 50亿      → 生成质量因子策略（避险偏好质量股）

板块资金流入集中在某板块           → 生成该板块相关的动量策略

融资余额5日增速 > 2%              → 生成短周期动量策略（杠杆资金推动短期趋势）
融资余额5日增速 < -2%             → 生成防御型策略（质量/价值）
```

### 3.3 这不是规则引擎，是数据驱动的参数空间

上面的映射不是 if-else 硬编码，而是：

1. **每个数据信号定义一个参数偏好区间**
2. **多个信号叠加时取交集**
3. **在交集范围内随机采样生成候选**

```python
# 示例：恐贪指数=25（恐惧）+ 波动率分量=30（高波动）+ reversal IC=0.04（反转有效）
# 三个信号叠加：

# 信号1（恐惧）偏好：RSI策略 oversold=[20,25,30], 价值策略 top_pct=[0.1,0.15]
# 信号2（高波动）偏好：长周期策略 period=[30,40,60], 高阈值 threshold=[0.03,0.05]
# 信号3（反转有效）偏好：RSI策略（强化），reversal因子策略

# 叠加结果：优先生成 RSI反转策略（period=14/21, oversold=20/25, overbought=75/80）
#           + 价值因子策略（top_pct=0.1, lookback=60）
#           + 多因子策略（reversal权重上调30%）
```

## 四、策略工厂实现

### 4.1 数据采集器（DataCollector）

每日18:05运行，把分散在各处的数据汇总成一个结构化的"今日数据快照"：

```python
@dataclass
class DailySnapshot:
    """今日数据快照 — 策略工厂的唯一输入"""
    date: date

    # 恐贪指数（直接从 calculate_fear_greed_index 获取）
    fear_greed_index: float          # 0-100
    fg_momentum: float               # 动量分量
    fg_volatility: float             # 波动率分量
    fg_volume: float                 # 成交量分量
    fg_breadth: float                # 广度分量（修复后）

    # 因子IC（从 factor_ic_history 表取最近值）
    factor_ic: Dict[str, float]      # {"momentum": 0.04, "value": -0.01, ...}
    factor_ic_5d_avg: Dict[str, float]  # 5日IC均值
    factor_ic_trend: Dict[str, str]  # {"momentum": "rising", "value": "falling", ...}

    # 资金流（从现有工具获取）
    north_fund_3d_net: float         # 北向资金近3日累计净买入（亿元）
    margin_5d_change_pct: float      # 融资余额5日变化率
    hot_sectors: List[str]           # 资金净流入前3板块名称
    cold_sectors: List[str]          # 资金净流出前3板块名称

    # 种群状态（从 strategies 表统计）
    listed_count: int                # 当前上架策略总数
    category_counts: Dict[str, int]  # 各分类数量
    incubating_count: int            # 孵化中数量
```

采集逻辑（全部复用现有代码）：

```python
class DataCollector:
    async def collect(self) -> DailySnapshot:
        # 1. 恐贪指数 — 调用现有 sentiment 服务
        index_klines = await db.get_klines('sh000001', limit=60)
        breadth = await db.get_limit_up_stats()  # 修复后可用
        fg = SentimentAnalyzer().calculate_fear_greed_index(index_klines, breadth)

        # 2. 因子IC — 直接查 factor_ic_history 表
        factor_ic = {}
        factor_ic_5d = {}
        factor_ic_trend = {}
        for fname in ["momentum", "value", "quality", "volatility", "reversal"]:
            rows = await db.fetch(
                "SELECT ic_value FROM factor_ic_history "
                "WHERE factor_name=$1 ORDER BY ic_date DESC LIMIT 20", fname)
            if rows:
                factor_ic[fname] = rows[0]['ic_value']
                ic_5d = mean([r['ic_value'] for r in rows[:5]])
                ic_20d = mean([r['ic_value'] for r in rows])
                factor_ic_5d[fname] = ic_5d
                delta = ic_5d - ic_20d
                factor_ic_trend[fname] = "rising" if delta > 0.01 else ("falling" if delta < -0.01 else "flat")

        # 3. 北向资金 — 调用现有 fund_flow 工具
        north = await get_north_fund(days=5)
        north_3d_net = sum(r['total'] for r in north[:3]) / 1e8  # 转亿元

        # 4. 融资数据 — 调用现有 margin 工具
        margin = await get_margin_data(days=10)
        if len(margin) >= 6:
            margin_5d_change = (margin[0]['totalBalance'] - margin[5]['totalBalance']) / margin[5]['totalBalance']
        else:
            margin_5d_change = 0.0

        # 5. 板块资金流 — 调用现有工具
        sectors = await get_sector_fund_flow()
        hot = [s['name'] for s in sectors[:3]]
        cold = [s['name'] for s in sectors[-3:]]

        # 6. 种群状态 — 查 strategies 表
        listed = await db.fetch("SELECT strategy_type, COUNT(*) as cnt FROM strategies WHERE status='listed' GROUP BY strategy_type")
        incubating = await db.fetchval("SELECT COUNT(*) FROM strategies WHERE status='incubating'")

        return DailySnapshot(
            date=date.today(),
            fear_greed_index=fg['index'],
            fg_momentum=fg['components']['momentum'],
            fg_volatility=fg['components']['volatility'],
            fg_volume=fg['components']['volume'],
            fg_breadth=fg['components']['breadth'],
            factor_ic=factor_ic,
            factor_ic_5d_avg=factor_ic_5d,
            factor_ic_trend=factor_ic_trend,
            north_fund_3d_net=north_3d_net,
            margin_5d_change_pct=margin_5d_change,
            hot_sectors=hot,
            cold_sectors=cold,
            listed_count=sum(r['cnt'] for r in listed),
            category_counts={r['strategy_type']: r['cnt'] for r in listed},
            incubating_count=incubating or 0,
        )
```

### 4.2 策略生成器（StrategySpawner）

输入 DailySnapshot，输出候选策略列表。逻辑完全由数据驱动：

```python
class StrategySpawner:
    """根据今日数据快照生成候选策略"""

    # 前端6个分类的最低配额
    CATEGORY_MIN = {"momentum": 5, "value": 5, "quality": 5, "growth": 5, "multi_factor": 5, "macro_timing": 5}

    def spawn(self, snapshot: DailySnapshot) -> List[dict]:
        candidates = []

        # ── 第一步：根据数据信号生成策略 ──

        # 恐贪指数驱动
        candidates += self._spawn_from_fear_greed(snapshot)

        # 因子IC驱动
        candidates += self._spawn_from_factor_ic(snapshot)

        # 资金流驱动
        candidates += self._spawn_from_fund_flow(snapshot)

        # ── 第二步：补齐分类缺口 ──
        candidates += self._spawn_for_gaps(snapshot)

        return candidates

    def _spawn_from_fear_greed(self, s: DailySnapshot) -> List[dict]:
        """恐贪指数 → 策略参数"""
        out = []
        fg = s.fear_greed_index
        vol = s.fg_volatility

        if fg < 30:
            # 恐惧区间 → 抄底型策略
            out.append(self._make("rsi", {"rsi_period": 14, "oversold": 25, "overbought": 75},
                                  reason=f"恐贪指数{fg:.0f}，市场恐惧，RSI抄底参数激进"))
            out.append(self._make("rsi", {"rsi_period": 6, "oversold": 20, "overbought": 80},
                                  reason=f"恐贪指数{fg:.0f}，短周期RSI快速捕捉超跌"))
            out.append(self._make("value_factor", {"factor_name": "value", "top_pct": 0.1, "lookback": 20},
                                  reason=f"恐贪指数{fg:.0f}，恐惧时精选深度价值股"))

        elif fg > 70:
            # 贪婪区间 → 追涨+逃顶型策略
            out.append(self._make("momentum", {"lookback": 5, "threshold": 0.01},
                                  reason=f"恐贪指数{fg:.0f}，贪婪期短周期动量追涨"))
            out.append(self._make("rsi", {"rsi_period": 14, "oversold": 35, "overbought": 65},
                                  reason=f"恐贪指数{fg:.0f}，贪婪期RSI逃顶阈值收紧"))
            out.append(self._make("ma_cross", {"short_period": 3, "long_period": 10},
                                  reason=f"恐贪指数{fg:.0f}，短周期均线快速跟踪"))

        else:
            # 中性区间 → 均衡型策略
            out.append(self._make("ma_cross", {"short_period": 5, "long_period": 20},
                                  reason=f"恐贪指数{fg:.0f}，中性市场标准均线"))
            out.append(self._make("momentum", {"lookback": 20, "threshold": 0.02},
                                  reason=f"恐贪指数{fg:.0f}，中性市场标准动量"))

        # 波动率分量驱动参数调整
        if vol < 35:
            # 高波动 → 拉长周期、提高阈值
            out.append(self._make("ma_cross", {"short_period": 10, "long_period": 60},
                                  reason=f"波动率分量{vol:.0f}，高波动用长周期均线过滤"))
            out.append(self._make("momentum", {"lookback": 30, "threshold": 0.05},
                                  reason=f"波动率分量{vol:.0f}，高波动提高动量阈值"))
        elif vol > 65:
            # 低波动 → 缩短周期、降低阈值
            out.append(self._make("ma_cross", {"short_period": 3, "long_period": 15},
                                  reason=f"波动率分量{vol:.0f}，低波动用短周期捕捉微弱趋势"))

        return out

    def _spawn_from_factor_ic(self, s: DailySnapshot) -> List[dict]:
        """因子IC → 策略参数"""
        out = []

        for fname, ic in s.factor_ic.items():
            trend = s.factor_ic_trend.get(fname, "flat")

            if ic > 0.03 and trend == "rising":
                # 这个因子最近很"灵" → 生成对应策略
                if fname == "momentum":
                    for lb in [5, 10, 20]:
                        out.append(self._make("momentum", {"lookback": lb, "threshold": 0.02},
                                              reason=f"momentum IC={ic:.3f}且上升，生成{lb}日动量"))
                elif fname == "value":
                    for tp in [0.1, 0.2]:
                        out.append(self._make("value_factor", {"factor_name": "value", "top_pct": tp, "lookback": 20},
                                              reason=f"value IC={ic:.3f}且上升，生成前{int(tp*100)}%价值"))
                elif fname == "quality":
                    out.append(self._make("quality_factor", {"factor_name": "quality", "top_pct": 0.2, "lookback": 20},
                                          reason=f"quality IC={ic:.3f}且上升"))
                elif fname == "reversal":
                    out.append(self._make("rsi", {"rsi_period": 14, "oversold": 30, "overbought": 70},
                                          reason=f"reversal IC={ic:.3f}且上升，反转因子有效"))
                    out.append(self._make("rsi", {"rsi_period": 6, "oversold": 25, "overbought": 75},
                                          reason=f"reversal IC={ic:.3f}且上升，短周期RSI"))

            elif ic < -0.02 and trend == "falling":
                # 这个因子最近"失灵" → 避免生成对应策略，或生成反向策略
                if fname == "momentum":
                    # 动量失灵 → 反转可能有效
                    out.append(self._make("rsi", {"rsi_period": 14, "oversold": 30, "overbought": 70},
                                          reason=f"momentum IC={ic:.3f}且下降，动量失灵转反转"))

        # 多因子策略：根据IC动态分配权重
        weights = {}
        for fname in ["momentum", "value", "quality", "volatility", "reversal"]:
            ic = s.factor_ic.get(fname, 0)
            trend = s.factor_ic_trend.get(fname, "flat")

            elif trend == "falling":
                weights[fname] = max(0.05, 0.2 - abs(ic) * 2)  # IC下降 → 减权
            else:
                weights[fname] = 0.2
        # 归一化
        total = sum(weights.values())
        weights = {k: round(v/total, 2) for k, v in weights.items()}
        out.append(self._make("multi_factor", {"factor_weights": weights, "top_pct": 0.2, "rebalance_days": 20},
                              reason=f"因子IC驱动权重分配: {weights}"))

        return out

        """资金流数据 → 策略参数"""

        # 北向资金信号
```

```python
class BacktestFilter:
    """用回测引擎筛选候选策略"""

    # 代表性股票（大盘+中盘+小盘各覆盖）
    TEST_STOCKS = ["600519", "000858", "601318", "600036", "000333",
                   "002415", "300750", "601012", "000001", "600276"]

    async def filter(self, candidates: List[dict]) -> List[dict]:
        passed = []
        for c in candidates:
            ok, metrics = await self._test_one(c)
            if ok:
                c['backtest_metrics'] = metrics
                passed.append(c)
        return passed

    async def _test_one(self, candidate: dict) -> Tuple[bool, dict]:
        # 拉取K线（复用现有数据源链）
        all_metrics = []
        for code in self.TEST_STOCKS:
            klines = await self._get_klines(code, days=500)
            if not klines or len(klines) < 100:
                continue
            result = BacktestEngine.run_backtest(
                code, klines, candidate['strategy_type'],
                {**candidate['params'], 'initial_capital': 100000, 'commission': 0.00025}
            )
            if result['success']:
                all_metrics.append(result['data'])

        if len(all_metrics) < 5:
            return False, {}

        # 取中位数（比均值更稳健）
        avg = {
            'sharpe_ratio': median([m['sharpe_ratio'] for m in all_metrics]),
            'total_return': median([m['total_return'] for m in all_metrics]),
            'max_drawdown': median([m['max_drawdown'] for m in all_metrics]),
            'win_rate': median([m['win_rate'] for m in all_metrics]),
            'trades_count': median([m['trades_count'] for m in all_metrics]),
        }

        # 筛选标准
        if avg['sharpe_ratio'] < 0.3:
            return False, avg  # Sharpe太低
        if avg['max_drawdown'] > 0.35:
            return False, avg  # 回撤太大
        if avg['trades_count'] < 3:
            return False, avg  # 交易次数太少，可能过拟合

        return True, avg
```

### 4.4 去重器（Deduplicator）

避免生成一堆参数相近的重复策略：

```python
class Deduplicator:
    """去除参数过于相似的候选策略"""

    def deduplicate(self, candidates: List[dict], existing_listed: List[dict]) -> List[dict]:
        result = []
        seen = existing_listed.copy()  # 已上架的也要比较

        for c in candidates:
            if self._is_duplicate(c, seen):
                continue
            result.append(c)
            seen.append(c)

        return result

    def _is_duplicate(self, candidate, existing) -> bool:
        for e in existing:
            if e['strategy_type'] != candidate['strategy_type']:
                continue
            # 同类型策略，比较参数相似度
            sim = self._param_similarity(candidate['params'], e.get('params', {}))
            if sim > 0.85:  # 参数相似度超过85%视为重复
                return True
        return False

    def _param_similarity(self, p1, p2) -> float:
        """参数相似度：数值参数的相对差异"""
        keys = set(p1.keys()) & set(p2.keys())
        if not keys:
            return 0.0
        similarities = []
        for k in keys:
            v1, v2 = p1[k], p2[k]
            if isinstance(v1, (int, float)) and isinstance(v2, (int, float)):
                if max(abs(v1), abs(v2)) == 0:
                    similarities.append(1.0)
                else:
                    similarities.append(1.0 - abs(v1 - v2) / max(abs(v1), abs(v2)))
        return mean(similarities) if similarities else 0.0
```

```python
        stype = ...  # 从DB取

        # 动量策略在恐惧市场中不适配

            FROM strategy_signals ss
            JOIN signal_forward_returns sfr ON sfr.signal_id = ss.id AND sfr.forward_days = 5

            AND ss.signal != 0

        if not rows or len(rows) < 3:
```

## 六、新增策略算法

### 6.1 需要新增的 IStrategy 子类

| 类名 | 注册名 | 输入 | 信号逻辑 |
|------|--------|------|----------|
| SingleFactorStrategy | — | closes + factor_name | 基类，按因子值排名打分 |
| ValueFactorStrategy | value_factor | closes | 基于价格序列估算PE/PB |
| QualityFactorStrategy | quality_factor | closes | 基于收益稳定性+低波动 |
| GrowthFactorStrategy | growth_factor | closes | 基于收益加速度 |
| MultiFactorStrategy | multi_factor | closes + factor_weights | 加权合成多因子 |
| MacroTimingStrategy | macro_timing | closes + volumes | 基于恐贪指数估算择时 |

关键约束：所有策略的 `generate_signals(closes, volumes)` 只接收价格和成交量数组，不接收外部数据。因子类策略需要从价格序列中**估算**因子值（技术面近似），而非直接读取基本面数据。

### 6.2 因子类策略的技术面近似

```python
class ValueFactorStrategy(SingleFactorStrategy):
    """价值因子策略 — 用价格序列近似估算"""

    def _compute_factor(self, closes, volumes=None) -> float:
        # 价值近似：低价格动量 + 高均值回归倾向
        # 逻辑：过去60日涨幅越低，"价值"越高（便宜）
        if len(closes) < 60:
            return 0.0
        ret_60d = (closes[-1] - closes[-60]) / closes[-60]
        # 均值回归强度：当前价格偏离60日均线的程度
        ma60 = np.mean(closes[-60:])
        deviation = (closes[-1] - ma60) / ma60
        # 价值得分 = -动量 - 偏离度（越低越"便宜"）
        return -(ret_60d * 0.5 + deviation * 0.5)
```

```python
class QualityFactorStrategy(SingleFactorStrategy):
    """质量因子策略 — 用收益稳定性近似"""

    def _compute_factor(self, closes, volumes=None) -> float:
        # 质量近似：收益稳定性高 + 波动率低 + 正收益占比高
        if len(closes) < 60:
            return 0.0
        returns = np.diff(closes[-60:]) / closes[-61:-1]
        stability = -np.std(returns)  # 波动越低质量越高
        positive_ratio = np.mean(returns > 0)  # 正收益天数占比
        return stability * 0.6 + positive_ratio * 0.4
```

```python
class GrowthFactorStrategy(SingleFactorStrategy):
    """成长因子策略 — 用收益加速度近似"""

    def _compute_factor(self, closes, volumes=None) -> float:
        # 成长近似：近期收益加速（20日收益 > 60日收益的年化）
        if len(closes) < 60:
            return 0.0
        ret_20d = (closes[-1] - closes[-20]) / closes[-20]
        ret_60d = (closes[-1] - closes[-60]) / closes[-60]
        # 加速度 = 短期收益率 - 长期收益率（正值=加速成长）
        acceleration = ret_20d - ret_60d / 3  # 60日收益折算到20日
        return acceleration
```

```python
class MacroTimingStrategy(IStrategy):
    """宏观择时 — 从价格序列估算恐贪指数"""

    def generate_signals(self, closes, volumes=None):
        signals = np.zeros(len(closes), dtype=np.int8)
        for i in range(self._lookback, len(closes)):
            fg = self._estimate_fear_greed(closes[i-self._lookback:i+1])
            if fg <= self._fear_threshold:
                signals[i] = 1   # 恐惧 → 买入
            elif fg >= self._greed_threshold:
                signals[i] = -1  # 贪婪 → 卖出
        return signals

    def _estimate_fear_greed(self, window) -> float:
        returns = np.diff(window) / window[:-1]
        momentum = 50 + np.mean(returns[-5:]) * 400
        vol = np.std(returns) * np.sqrt(252)
        volatility = 75 - vol * 800
        return float(np.clip((momentum + volatility) / 2, 0, 100))
```

```
   - 因子IC驱动：~10个候选（每个有效因子2-3个变体）
   - 资金流驱动：~4个候选
   - 分类缺口补位：6类 × 5个 = 30个候选（因为全部为空）
   - 总计：~50个候选
3. BacktestFilter → 通过率约50% → ~25个
4. Deduplicator → 去重后 ~20个
5. StrategySubmitter → 质检通过率约70% → ~14个进入 incubating
6. 第二天重复，因为 listed_count 仍为0，继续大量生成
7. 约3-5天后 incubating 积累到 30+ 个
8. lifecycle_scan 逐步将表现好的 incubating → listed
9. 约2-4周后 listed 达到 30+ 个，前端6个Tab都有商品
```

## 九、nav_series 补齐

```python
async def compute_nav_series(strategy_id: str) -> List[float]:
    """从 signal_forward_returns 计算策略累计净值"""
    rows = await db.fetch("""
        SELECT ss.signal_date, ss.signal, sfr.actual_return
        FROM strategy_signals ss
        JOIN signal_forward_returns sfr ON sfr.signal_id = ss.id AND sfr.forward_days = 5
        WHERE ss.strategy_id = $1 ORDER BY ss.signal_date
    """, strategy_id)

    daily_returns = {}
    for r in rows:
        ret = r['actual_return'] * (1 if r['signal'] == 1 else -1)
        daily_returns.setdefault(r['signal_date'], []).append(ret)

    nav = [1.0]
    for d in sorted(daily_returns):
        avg = sum(daily_returns[d]) / len(daily_returns[d])
        nav.append(nav[-1] * (1 + avg))

    # 降采样至30点给前端迷你图
    if len(nav) > 30:
        nav = nav[::len(nav)//30][:30]
    return nav
```

在 strategy_manager 的 `rank` 和 `detail` action 返回值中附加 `nav_series`。
