# 历史方案归档

本目录存放“仍有参考价值，但不应再作为当前开发入口”的材料。归档标准如下：

1. 文档本身已经明确声明是历史方案、阶段性审计或研究蓝图。
2. 当前仓库没有稳定入口继续直接依赖它的原路径。
3. 继续平铺在 `docs/plans/` 顶层会显著增加阅读噪音。

## 使用边界

- 归档文档可以提供背景和论证，但不能直接当作当前任务清单。
- 如果归档文档里的结论要重新拿出来落地，必须先和当前代码、测试结果、运行基线重新校准。
- 若某篇归档文档重新成为现行入口，应从 `archive/` 迁回，并在 [`../README.md`](../README.md) 中恢复入口。
