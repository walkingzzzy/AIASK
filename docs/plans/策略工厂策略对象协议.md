# 策略工厂策略对象协议

## 目标

统一策略工厂在生成、回测、提交、评审、孵化阶段使用的策略对象协议，避免各阶段对“策略候选”理解不一致。

## 最小必填字段

- `strategy_type`
- `params`
- `target_symbols`
- `stock_pool`
- `hypothesis`
- `holding_horizon`
- `rebalance_rule`
- `portfolio_spec`
- `execution_assumptions`
- `validation_profile`
- `targeting_policy`
- `constraint_check`

## 推荐扩展字段

- `trade_plan`
- `risk_rules`
- `position_sizing`
- `execution_notes`
- `selection_logic`
- `event_context`
- `research_task`
- `task_signature`

## 对象分层

### 1. StrategyResearchContract

研究任务与候选绑定的任务合同。

关键字段：

- `task_id`
- `task_source`
- `opportunity_type`
- `preferred_strategy_types`
- `allowed_strategy_types`
- `preference_strength`
- `target_symbols`
- `stock_pool`
- `target_symbol_policy`
- `universe_expansion_policy`
- `validation_focus`
- `event_window`
- `estimation_window`
- `holding_window`
- `task_signature`

### 2. StrategyTargetingPolicy

描述候选目标池与研究任务目标池的关系。

关键字段：

- `target_symbol_policy`
- `universe_expansion_policy`
- `validation_focus`
- `constraint_violation`
- `expansion_applied`
- `expansion_reason`
- `expansion_source`
- `coverage_ratio`
- `intersection_ratio`

### 3. StrategyPortfolioSpec

描述组合或仓位语义。

关键字段：

- `position_assumption`
- `target_weight_scheme`
- `max_position_pct`
- `target_weight_map`

### 4. StrategyExecutionAssumptions

描述执行与成本口径。

关键字段：

- `commission_rate`
- `slippage_bps`
- `slippage_model`
- `market_impact_bps`
- `tradability_filter`
- `capacity_participation_rate`
- `adv_ratio_limit`
- `capacity_bucket`

### 5. StrategyValidationProfile

描述 Gate-1 / Gate-2 / Gate-3 的主验证协议。

关键字段：

- `profile`
- `validation_focus`
- `primary_validation_layer`

### 6. StrategySubmissionAudit

描述提交与审计结果。

关键字段：

- `constraint_check`
- `attempt_adjustment`
- `task_signature`
- `refresh_mode`
- `primary_validation_layer`
- `event_window_config`
- `cost_assumptions`
- `explicit_cost_breakdown`
- `implicit_cost_breakdown`
- `position_assumption`

## 内部字段与对外展示字段映射

### 内部字段

- `research_task`
- `event_context`
- `constraint_check`
- `targeting_policy`
- `validation_profile`
- `attempt_adjustment`
- `task_signature`
- `refresh_mode`

### 对外展示字段

- `strategy_type`
- `name`
- `description`
- `hypothesis`
- `target_symbols`
- `stock_pool`
- `holding_horizon`
- `rebalance_rule`
- `portfolio_spec`
- `execution_assumptions`
- `risk_rules`
- `position_sizing`
- `backtest_metrics`
- `quality_gate`

### 映射规则

- `research_task.target_symbols` 与 `constraint_check.target_symbols_after_normalize` 共同决定最终 `target_symbols`
- `execution_assumptions`、`portfolio_spec`、`risk_rules` 会在回测与评审阶段转为执行审计和容量审计字段
- `validation_profile` 决定 Gate-3 主判定逻辑
- `task_signature` 与 `refresh_mode` 共同决定是刷新旧策略还是派生新实验
