# 策略说明闭环（为什么生成 / 为什么孵化）

> 更新：2026-07-13  
> 解决：策略工厂会生产策略，但用户看不到**为什么这样生成、为什么这样孵化**。

## 契约

| 版本 | 模块 | 用途 |
| --- | --- | --- |
| `strategy_explanation.v1` | `aiask_quant_core.strategy_explanation` | 为什么生成 + 怎么交易 + 风险 + 生成证据 |
| `incubation_explanation.v1` | 同上 | 为什么孵化/卡住 + next_evidence_needed |
| `strategy_case_file.v1` | 同上 | 合并生成+孵化案卷 |

关键函数：

- `ensure_strategy_explanation()` — 生成说明并附 `completeness`
- `evaluate_strategy_explanation_completeness()`
- `build_incubation_explanation()`
- `build_strategy_case_file()`
- `explain_reason_code()` — blocker 码中文映射

## 接线

1. **提交落库**：`submission_flow` 使用 `ensure_strategy_explanation`，写入 `params.strategy_explanation`  
2. **规则生成**：rule generator 的 `generation_reason` 补 `rationale`  
3. **孵化 intake**：domain event 携带 explanation  
4. **展示**：`build_strategy_presentation` 输出  
   - `why_generated` / `why_incubating` / `why_blocked`  
   - `strategy_case_file` / `explanation_completeness`  
5. **市场摘要**：list/rank 外溢 `why_generated` + completeness  
6. **诊断**：`top_blockers[].detail_zh`  
7. **Desktop**  
   - 策略工厂页：领域事件「为什么生成 / 为什么孵化」表  
   - Formal blockers：中文说明列  
   - 我的策略：列表「为什么生成」列
