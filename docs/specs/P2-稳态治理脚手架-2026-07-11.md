## 1. Endpoint drift

### 原则
- Desktop **只**走 Agent HTTP（`packages/agent` 暴露的 ops / finance / readiness）。
- 禁止新增 Desktop → MCP / SQLite 直连。
- 遗留 `desktop-api` 只读过渡：列清单 → 代理到 Agent → 废弃。

### 检查
- CI job `boundary-and-drift`（`.github/workflows/ci.yml`）继续作为边界守门。
- 手工：`rg "localhost:8|mcp|/api/desktop" desktop/src` 排查越权调用。

### 目标清单（维护）
| 遗留面 | 处置 |
| --- | --- |
| 任何 Desktop 直连 finance MCP | 改 Agent tool / intent |
| 脚本写 formal 库 | 改 Intent dry-run 默认 |
| 双 endpoint 同语义 | 以 Agent 契约为权威 |
