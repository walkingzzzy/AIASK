## 新增发现（v2 未覆盖）

1. **ROOT-1 根因闭环**：v2 仅观察到 000001 混淆现象，v3 通过 dead-letter 锁定入库校验器根因（`index_close_out_of_range` 拒绝平安银行真实股价）并精确定位污染面（直读 db.stock_quotes 的路径）
2. **ROOT-3 payload 爆炸**：v3 深入 strategy_manager/workflow 发现 factory run 内嵌（v2 未触及策略超市）
3. **决策逻辑系统性偏差**：smart_stock_diagnosis 全标的 sell / should_i_buy 概率失校准 / valuation_consensus 内部失败（v2 仅浅测）
4. **因子系统完整审计**：alias 契约不一致(pb_ratio) / IC 管道 IndexError / robustness 100%不可用 / crowding 常量（v2 未覆盖因子深度）
5. **技能系统**：executable/registered_only 拆分 / run_skill payload 翻倍 / 中文搜索失效（v2 无此场景）
6. **交易计划/关键价位**：entry=0/负产出负止损负股数 / signal_decay 恒报误警 / scenario 仓位超风格上限（v2 无此场景）
7. **条件收益引擎**：MA 族字段 DataFrame.tolist 崩溃 / 未识别 field 静默0（v2 无此场景）

## 结论

v3 在 v2 基础上实现了 **15x 调用深度** 和 **全工具覆盖**，锁定了 v2 仅观察到现象的 **系统级根因**，并发现了大量 v2 未触及领域（策略超市/因子系统/技能系统/交易计划/条件收益）的深层缺陷。三大基线锚点全程稳定证明工具注册表本身健壮，问题集中在数据层（000001污染）、输入校验层（非法码坐标化）和决策逻辑层（系统性偏差）。
