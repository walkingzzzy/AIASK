# 目标
帮助投资者理解托管风险、保护范围与不被保护的事项，避免误解。

# 使用流程
- 适用地区：先确认投资者所在地区/开户券商所在地。
- 保护机制：解释当地投资者保护机制的范围与限制（仅做信息性说明）。
- 风险边界：强调市场波动损失不属于保护范围，强调分散与风险承受能力。
- 操作建议：给出合规性与信息披露核验清单（不含投资建议）。

# 失败与兜底
- 地区不明确：只提供通用框架，并提示需要明确地区再做细化说明。

# 参考
- 若需具体法规/机构信息，提示用户授权联网检索。
