## 1. 功能设计

| 项 | 内容 |

### 1.4 业务规则与边界

量化研究是报告和证据，不是策略工厂入口；任何后续执行、投递或调度动作进入 intent。

## 2. 流程设计

状态机：`loading_presets -> ready -> running -> report_ready|failed|data_blocked`。

| 步骤 | 用户操作 | API | 异常 |
|---|---|---|---|
| 加载预设 | `/v1/desktop/quant/presets` | no presets empty |
| 运行研究 | `POST /research-runs` | data gate failed |
| 查看报告 | `/research-runs/{id}/report` | report missing |

### 11.3 状态和响应式

- `gated`：数据门禁失败时运行按钮 disabled 或显示修复路径。
- `success`：报告必须能追到 research id、run id、stage evidence 和 raw JSON。
- 窄屏参数表单置顶，阶段和报告纵向排列；图表/指标卡避免横向溢出。

## 功能目标

量化研究用于从数据、因子、回测参数和风险设定生成结构化研究 run 与报告。V1 量化研究必须独立于 Strategy Factory，不跳转、不推荐四工厂。

## 用户流程

1. 打开 Quant Research，加载 presets。
2. 用户选择 universe、因子、benchmark、rebalance、cost、slippage。
3. 页面先检查 data gate。
4. 点击运行创建 research run。
5. 运行后展示阶段结果：数据、因子、回测、风险、报告。
6. 用户可输入 research_id 读取历史报告。

## 验收规则

1. 所有请求使用 API token。
2. 创建研究 body 明确包含 universe/factors/benchmark/cost/slippage。
3. data gate blocked 时不能显示成成功研究。
4. 报告必须带非投资建议和证据来源。
5. 不请求 strategy/factor/incubation/factory-events 路径。

## 详细落地规范

### 问题场景与技术方案

| 问题 | 表现 | 技术方案 | 代码落点 | 验收 |
|---|---|---|---|---|
| 用户不会配置研究参数 | preset + 表单解释 | `/v1/desktop/quant/presets` | `quant_research.py` | 默认值可见 |
| 数据缺失 | data gate blocked | `agent_quant_data_gate` | `adapters/quant.py` | 不创建假研究 |
| 研究运行失败 | stage error 可见 | research run stage model | `desktop_finance.py` | 错误和 next steps 可见 |
| 报告无证据 | 报告包含 artifacts/sources | report payload | `QuantResearchWorkspace.tsx` | 来源可追踪 |
| 误跳策略工厂 | 后续动作只到报告/Workbench | V1 route negative | tests | 无 factory endpoint |

### 报告结构

| 部分 | 内容 |
|---|---|
| Summary | 研究目的、universe、benchmark |
| Data Gate | 数据状态和缺口 |
| Factor Results | 因子表现、IC、稳定性 |
| Backtest | 收益、回撤、换手、成本 |
| Risk | 风险、样本、限制 |
| Evidence | 数据源、run id、artifacts |
| Disclaimer | 非投资建议 |

### 代码生成/修改步骤

1. 新研究字段先扩展 quant preset 和 run payload。
2. 前端表单必须校验 cost/slippage/benchmark/universe。
3. 研究 run 返回 stage 状态，不只返回最终文本。
4. mock 覆盖 data blocked、running、failed、report success。
5. 单测断言不请求 strategy/factor/incubation/factory-events。

### 不做什么

- 不生成交易建议。
- 不跳转 Strategy Factory。
- 不在数据不足时生成漂亮但无依据的报告。

### 状态机补充

`presets_loading -> presets_ready -> form_validating -> data_gate_checking -> ready_to_run -> running -> report_ready/report_failed`

数据阻断状态为 `blocked_local_database_required`、`blocked_stale_data`、`blocked_missing_universe`。
