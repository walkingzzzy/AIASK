## 2. 流程设计

| 步骤 | 用户操作 | 前端行为 | Agent/API | 异常 |
|---|---|---|---|---|
| 1 | 打开市场温度 | 加载 snapshot/cache | read-only tools | cache stale |
| 2 | 查看行业 | 加载行业历史/成分 | industry methods | 无数据 empty |
| 3 | 查看验证 | 加载 forward validation | validation tool | 降级显示 |
| 4 | 联动研究 | 跳 Radar/Quant/Financial Manager | route/view | 不跳四工厂 |

状态机：`loading -> ready|stale|empty|error|mock -> refreshing -> success|failed`。

## 10. 代码实证与成熟实现补强

### 10.1 当前代码审计

| 对象 | 代码证据 | 当前行为 | 文档结论 |
|---|---|---|---|
| 页面 | `desktop/src/features/market-temperature/MarketTemperatureWorkspace.tsx` | 读取 snapshot/cache readiness/cache history/industry history/constituents/forward validation | 市场温度是只读分析页，不产生策略工厂动作 |
| API | `AiaskApi.marketTemperatureSnapshot()` 等 | 使用 read-only Agent tool facade | endpoint 表要写工具名和只读属性 |
| UI 状态 | 代码内有 `degraded`、`stale`、`missing`、`not_ready`、`benchmark fallback` 映射 | 数据质量和缓存状态必须显示 | 不可把缓存 fallback 写成 live ready |
| 测试 | `MarketTemperatureWorkspace.test.tsx` | 断言 read-only refresh 不请求 `/intents|strategy|factor|incubation|factory-events` | QA 必须保留四工厂负向 |

### 10.2 功能细节

| 功能 | 展示字段 | 验收 |
|---|---|---|
| Snapshot | temperature、breadth、industry ranks、updated_at、quality | 数据源和时间可见 |
| Cache readiness | ready/degraded/missing/stale/failed | 缓存不新鲜时提示 Data & Sync |
| Industry history | 行业趋势、冷热变化 | 表格/图表必须有稳定尺寸 |
| Forward validation | 前向验证结果 | 不写成买卖建议 |

### 10.3 成熟技术采用

Lightweight Charts 官方文档用于金融图表的轻量绘制和 API 参考；TanStack Table/Virtual 用于长表格和可筛选列表。AIASK V1 可以采用轻量图表和表格展示数据，但必须标注数据来源、缓存状态和更新时间；不采用复杂交易终端式实盘操作。

## 功能目标

热力图与市场温度用于回答“当前市场哪里热、哪里冷、行业宽度如何、这个温度状态是否有历史验证”。它应服务 AI 对话、股票雷达、金融工作台和量化研究，不是单独装饰图。

## 代码证据

| 能力 | 代码位置 |
|---|---|
| 前端页面 | `desktop/src/features/market-temperature/MarketTemperatureWorkspace.tsx` |
| API client | `marketTemperatureSnapshot`、`marketTemperatureCacheReadiness`、`marketTemperatureCacheHistory`、`marketTemperatureIndustryHistory`、`marketTemperatureIndustryConstituents`、`marketTemperatureForwardValidation` |
| Agent 工具调用 | `desktop/src/services/aiaskApi.ts` 通过 `/v1/tools/agent_market_temperature_*` |

| DB readiness | `packages/akshare-mcp/src/akshare_mcp/tools/db_freshness.py` 的 market temperature readiness |

## 用户流程

1. 打开市场温度，自动读取缓存 readiness 和 snapshot。
2. 页面展示整体温度、上涨/下跌宽度、热点行业、冷门行业。
3. 用户选择日期、top_n、样本数量，刷新快照。
4. 点击行业查看成分股和历史温度。
5. 前向验证显示不同 horizon 下状态命中率和 benchmark fallback。
6. 热力图结果可作为 Workbench 右侧金融上下文。

## 验收规则

1. 所有市场温度调用必须是 `/v1/tools/agent_market_temperature_*`。
2. 页面不得触发 strategy/factor/incubation/factory-events endpoint。
3. 数据降级、benchmark fallback、样本不足必须可见。
4. 移动端热力图不横向溢出，文本不覆盖色块。
5. 热力图颜色必须有图例，不能只靠颜色传达风险。

## 详细落地规范

### 问题场景与技术方案

| 问题 | 前端表现 | 技术方案 | 代码落点 | 验收 |
|---|---|---|---|---|
| 用户不知道市场整体冷热 | 顶部温度仪表和宽度指标 | snapshot tool 聚合涨跌/行业 | `agent_market_temperature_snapshot` | as_of/sample_count 可见 |
| 热力图数据过期 | 黄色 degraded，提示同步缓存 | cache readiness | `agent_market_temperature_cache_readiness` | stale_days 可见 |
| 行业热点无法追溯 | 点击行业显示历史和成分股 | industry history/constituents | market_temperature tools | 抽屉展示来源 |
| benchmark 不可用 | 前向验证显示 fallback | forward validation 返回 fallback reason | `get_market_temperature_forward_validation` | 不隐藏 fallback |
| 样本数不足 | 不画强结论，显示样本不足 | min_samples gate | helpers validation | hit_rate 标注 insufficient |
| 移动端色块挤压 | 热力图降级为列表/两列 | CSS responsive grid | `MarketTemperatureWorkspace.tsx` | 无横向滚动 |

### 热力图视觉标准

| 维度 | 规则 |
|---|---|
| 色彩 | 热/冷/中性至少三类，不使用单一色系 |
| 图例 | 必须显示温度区间和含义 |
| 文本 | 色块内只放短标签，长名称放 tooltip/列表 |
| 辅助信息 | hover/focus 显示 source、sample、as_of |
| 可访问性 | 不能只靠颜色，需数值/标签 |

### 代码生成/修改步骤

1. Market Temperature 页面只调用 `AiaskApi.marketTemperature*` 方法。
2. 新增可视化字段时先确认 AKShare MCP payload 是否提供，缺失时由 Agent facade 补齐。
3. mock 覆盖 ready、stale、benchmark fallback、empty、tool error。
4. 测试断言所有请求 URL 包含 `agent_market_temperature_`，且不包含四工厂关键词。

### 不做什么

- 不把热力图当装饰背景。
- 不用没有样本的数据画结论。
- 不跳转策略工厂。
- 不隐藏缓存来源。

### 状态机补充

`readiness_loading -> readiness_ready -> snapshot_loading -> snapshot_ready/snapshot_empty/snapshot_error`

行业详情为 `industry_idle -> history_loading -> history_ready -> constituents_loading -> constituents_ready`。前向验证为 `validation_loading -> validation_ready/validation_degraded`。
